# 导出内容审核记录

你可以导出内容审核记录，例如导出单聊或群聊的审核记录。

1. 登录 [环信控制台](https://console.easemob.com/user/login)。 
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **功能配置 > 增值服务 > 内容审核 > 审核记录导出**。
4. 设置筛选条件，点击 **导出** 导出内容审核记录。
5. 在 **导出记录** 中下载导出的文件。导出的文件仅在服务器保存 7 天，需及时下载。
