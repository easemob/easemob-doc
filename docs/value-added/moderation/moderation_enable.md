# 开通内容审核服务

为帮助开发者构建安全、干净的即时通讯环境，环信即时通讯 IM 提供多维度的内容审核服务。该服务可对用户发送的消息内容（包括文本、图片、音视频等）进行智能审核，并基于审核结果执行相应的处理策略（如拦截或下发），有效降低内容违规风险。

## 前提条件

- 已注册有效的环信即时通讯 IM 开发者账号；
- 账户余额不低于 500 元。

## 开通流程

1. 登录 [环信控制台](https://console.easemob.com/user/login)。 
2. 在页面顶部导航栏选择 **应用管理** 进入 **应用列表** 页面，选择你的应用，点击 **操作** 栏中的 **管理**。
   
   ![img](/images/console/app_mgmt_list.png)
   
3. 在左侧导航栏选择 **增值服务** > **内容审核**。
4. 选择右侧的 **内容审核** 页签，根据业务需求开通相应服务：
   - 文本审核
   - 图片审核
   - 音频审核
   - 视频审核服务
   - 消息举报

:::tip
- 免费版套餐包在账户余额充足的情况下，也可付费开通内容审核服务。
- 如需使用自定义消息审核，请先开通文本审核和图片审核，再联系商务开通自定义消息审核。
:::

服务开通后，你可参考 [配置文档](moderation_rule_config.html) 对内容审核规则进行个性化设置。
