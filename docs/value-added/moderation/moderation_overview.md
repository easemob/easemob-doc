## 功能描述

内容审核提供多种能力，帮助你定义消息审核规则，并满足不同业务场景下的内容检测需求：

- 多消息类型审核：支持对文本、图片、音频和视频消息进行审核。
- 多维度消息审核：支持按单聊、群聊、聊天室等维度细分消息，并分别配置审核规则。
- 自定义消息处置规则：可根据审核结果自定义消息下发或拦截策略，保障消息处理结果符合业务需求。
- 审核结果回调：支持将审核结果回调至你的服务器，便于同步审核数据并执行后续业务处理。
- 一站式管理后台：提供可视化内容审核后台，支持审核记录查询、数据统计、自定义名单管理等功能，帮助你统一管理审核业务。
- 满足业务多场景的审核模型检测需求：
  - 智能文本识别：支持识别涉政、违禁、暴恐、色情、辱骂、广告及垃圾文本内容，并支持自定义词库检测。
  - 智能图片识别：支持识别涉政、违禁、暴恐、色情、广告类图片，以及图片中的违规文字，并支持自定义图片检测。
  - 智能音频识别：支持识别涉政、违禁、暴恐、色情、辱骂、广告及娇喘等语音内容。
  - 智能视频识别：支持识别涉政、违禁、暴恐、色情、辱骂、广告类视频内容，以及 LOGO 水印。

## 应用场景

### 社交平台

可识别单聊、群聊中各类消息里的涉政、色情、辱骂、暴恐、广告导流等风险内容，帮助净化应用内聊天环境。

### 直播聊天室

可识别聊天室消息或直播弹幕中的涉政、涉黄、暴恐、广告导流等风险内容，支持实时识别，降低聊天室运营成本。

### 游戏互动

可实时识别游戏公屏聊天消息中的涉政、涉黄、暴恐、广告导流等风险内容，帮助你对风险内容进行有效管理，减少业务风险。
