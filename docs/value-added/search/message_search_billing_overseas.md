# 海外计费说明

本文介绍服务端消息搜索的海外计费规则，适用于新加坡集群的应用。国内计费规则详见 [国内计费说明](message_search_billing_domestic.html)。

服务端消息搜索按套餐订阅费用和超量使用费用计费。索引量与请求量分别统计、分别计算超量费用。

## 免费试用

仅测试版应用可免费试用服务端消息搜索，试用时长为 7 天。开通方式详见 [开通消息搜索](/product/console/purchase_value_added.html#消息搜索)。

## 套餐内订阅费用

| 套餐费用 | 每月包含索引量 | 每月包含请求量 |
| :--- | :--- | :--- |
| 2999 元/月 | 150 万条 | 30 万次 |

首月开通时，费用与额度将根据该月剩余天数按比例折算。

## 超出套餐费用

当月套餐的索引量或请求量额度消耗完毕后，超出部分按实际使用量计费：

| 计费项 | 超量计费单价 | 计费说明 |
| :--- | :--- | :--- |
| 索引量 | 30 元/3 万条 | 按超出当月套餐索引量额度的实际用量计费。 |
| 请求量 | 30 元/1 万次 | 按超出当月套餐请求量额度的实际用量计费。 |

当月实际应付费用由套餐订阅费用和超量使用费用共同构成。
