# 海外计费说明

本文介绍消息翻译的海外计费规则。国内计费规则详见 [国内计费说明](message_translation_billing_domestic.html)。

消息翻译按套餐订阅费用和超量使用费用计费。计费字符数按 **源文本字符数 × 目标语言数量** 计算。例如，将 500 个字符翻译为 4 种语言，计费字符数为 2,000。

## 免费试用

消息翻译服务提供总计 50 万字符的免费试用额度。开通方式详见 [开通消息翻译](/product/console/purchase_value_added.html#消息翻译)。

## 套餐内订阅费用

| 套餐费用 | 每月包含字符数 |
| :--- | :--- |
| 1000 元/月 | 400 万字符 |

## 超出套餐费用

当月套餐的字符额度消耗完毕后，超出部分按以下标准计费：

| 计费项 | 超量计费单价 |
| :--- | :--- |
| 翻译字符数 | 0.27 元/1000 字符 |

当月实际应付费用由套餐订阅费用和超量使用费用共同构成。
