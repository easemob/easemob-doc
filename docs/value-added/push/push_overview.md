# 即时推送服务介绍

## 服务简介

环信即时推送服务，致力于为开发者提供高效、稳定、安全的消息触达能力。

依托低延时、高送达、高并发的服务优势，帮助企业在系统通知、营销活动、内容分发等场景中，实现更精准、更及时的用户连接，持续提升活跃度与业务增长效率。

## 服务特性

**高效触达，稳定可靠**
具备低延时、高送达、高并发的服务能力，支持毫秒级消息触达；在线消息送达率高达 99.99%，为业务稳定运行提供有力保障。

**一站式集成，接入便捷**
集成一套 IM SDK，即可同时获得即时通讯与推送能力，显著降低接入门槛，缩短开发周期，加速业务上线。

**安全合规，无痕推送**
环信专注于提供专业的推送服务，SDK 不采集用户隐私数据，符合相关数据安全与隐私合规要求，让企业接入更安心、运营更放心。

**全程加密，通信无忧**
采用私有二进制通信协议，对数据传输过程进行全链路加密，全面保障消息传输安全。

**专业服务，全程支持**
提供专业技术支持与服务保障，快速响应客户需求，协助开发者高效完成接入、运营与问题排查。

## 核心功能

**多厂商通道覆盖**
支持 Google、华为、小米、魅族、OPPO、vivo 等主流手机厂商通道，并支持 iOS 双证书配置，全面提升多平台消息送达能力。

**推送管理与数据分析**
提供便捷易用的推送管理后台，无需额外开发，即可完成推送创建、用户管理、推送查看与数据分析，帮助企业提升推送运营效率。

**开放灵活的接口能力**
提供 REST 接口，支持灵活发起推送任务，轻松实现业务消息自动触发，满足多样化业务场景需求。

## 应用场景

**系统消息通知**
适用于好友通知、订单提醒、预约结果、服务变更等场景，帮助企业第一时间将关键信息传递给用户，提升服务体验与转化效率。

**营销活动触达**
适用于促销活动、节日营销、限时福利、品牌推广等场景，通过精准触达目标用户，提升活动参与度与营销转化效果。

**用户运营促活**
面向新用户引导、沉默用户召回、活跃用户维护等场景，支持更精细化的用户运营策略，助力提升留存与活跃增长。

**社交互动提醒**
在点赞、评论、分享、红包、私信等社交互动场景中，及时提醒未打开应用的用户，增强互动频次与产品黏性。

**内容订阅分发**
适用于资讯、内容、视频等业务场景，可向用户及时推送关注内容与热门信息，提升打开率、阅读量与内容消费活跃度。
