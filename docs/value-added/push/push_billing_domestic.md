# 国内计费说明

环信推送服务提供免费版和专业版两个版本。不同版本的计费模式与功能详情如下。

系统每月 1 日出推送服务账单，统计上月峰值 DAU（日活跃用户数）使用情况，并根据实际用量从账户余额中扣除相应费用。你可登录 [环信控制台](https://console.easemob.com/user/login)[查看费用详情](/product/console/account_center.html#查看消费账单)。

| 项目    | 免费版    | 专业版     | 
| -------- | ---------- | ---------- |
| 适用场景 | 适用于开发阶段或轻量级推送应用的测试与体验   | 适用于生产环境的规模化推送服务，按月峰值 DAU 阶梯计价 | 
| 计费模式 | 免费版支持 100 个注册用户，超出后自动按专业版计费 | 按月峰值 DAU 计费，288 元/1万 DAU（开通即包含 1万 DAU）           | 

## 免费试用

| 价格 | 计费项     | 说明 |
| :----- | :------- | :------- |
| 免费  | - 推送日活：≤ 100 设备 <br/> - 推送速度：5 条/秒   | 适合开发测试或初期试运营阶段。|

## 套餐内订阅费用

| 价格 | 计费项     | 说明 |
| :--- | :----- | :------- |
| 288 元/月  | - 推送日活：≤ 10,000 设备（免费峰值） <br/> - 推送速度：10,000 条/秒   | 支持高并发业务场景，保障大规模用户实时触达。|

## 超出套餐费用

超出套餐部分按以下标准计费：

| 计费项   | 价格             | 说明                             |
| :------- | :--------------- | :------------------------------- |
| 推送日活 | 288 元/万推送日活/月 | 按超出套餐的推送日活用户数计费。 |
