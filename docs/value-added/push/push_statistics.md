# 推送数据统计

环信推送提供推送数据统计。[开通即时推送](push_task_create.html#开通服务) 后，若进行了通知推送，可在环信控制台选择 **运营管理** > **推送管理** > **推送统计**，查看推送数量统计、推送成功率和推送厂商通道占比。

## 按天统计推送数据

环信推送提供按天统计的推送详情，如下图所示：

![img](/images/console/push_statistics_1.png)

| 统计维度    | 描述   | 
| :------- | :----- | 
| 推送数量 | 包括推送成功数、推送失败数、推送未知数。<br/> - 推送失败的原因包含不具备推送条件（如未配置证书、没有绑定设备）以及厂商返回失败（如 bad device token、通道限额等原因）。<br/> - 推送未知的原因为环信服务器端未知异常。| 
| 推送成功率  | 推送的成功率。  | 
| 推送厂商通道占比  | 各推送厂商通道的推送数比例。 | 

## 按时间段统计推送数据

环信推送提供一定时间段的推送数据及推送指标统计详情，如下图所示：

![img](/images/console/push_statistics_2.png)

| 统计维度    | 描述   | 
| :------- | :----- | 
| 推送数量 | 各个通道（全部、环信在线通道、谷歌、华为、小米、魅族、OPPO、VIVO、APNs）的推送详情：推送成功数、推送失败数、推送未知数。| 
| 推送指标  | 全部通道（包含环信在线通道、小米、魅族、VIVO、APNS）、环信在线通道、小米、魅族、VIVO、APNS 通道的发送数、送达数、点击数。 |
