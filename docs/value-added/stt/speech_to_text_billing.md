语音转文字服务提供将语音内容转换为文本的能力，适用于需要对音频内容进行识别、转写和文本处理的业务场景。

首次开通语音转文字服务后，可免费试用：

- 试用过程中，关闭服务需联系环信商务。

## 套餐内订阅费用

语音转文字服务套餐说明如下：
- 套餐包价格为 500 元/月。
- 开通套餐包后，每月赠送 5 万条免费额度。
- 首月开通时，费用与免费额度将根据该月剩余天数按比例折算。

当月实际应付费用由套餐订阅费用和超量使用费用共同构成。
