# 语音转文字计费说明

语音转文字服务提供将语音内容转换为文本的能力，适用于需要对音频内容进行识别、转写和文本处理的业务场景。

## 免费试用

首次开通语音转文字服务后，可免费试用：
- 试用总额度为 3000 次。
- 试用有效期为 1 年，当试用额度用尽或试用到期后，系统自动关闭服务。
- 试用过程中支持关闭服务。

## 套餐内订阅费用

语音转文字服务套餐说明如下：
- 套餐包价格为 500 元/月。
- 开通套餐包后，每月赠送 5 万条免费额度。
- 套餐包按照当月剩余天数折算扣费。

## 超出套餐费用

当月套餐的赠送额度消耗完毕后，超出部分按实际使用量计费，即按 0.01 元/条计费。

当月实际应付费用由套餐订阅费用和超量使用费用共同构成。

## 关闭规则

- 试用过程中支持关闭服务。
- 正式开通后，需要联系环信商务关闭该服务。
