# 开通语音转文字

按如下步骤开通语音转文字服务：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。 
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **增值服务 > 语音转文字**。
4. 进入页面后，勾选 **我已阅读并同意《隐私政策》及《计费说明》**，然后根据需要点击 **立即试用** 或 **正式开通**。

## 免费试用

在 **语音转文字** 页面，点击 **立即试用**，在弹出的对话框中，可查看试用期间的请求次数总量限制，确认无误后，选择 **我已知晓，立即试用**，即可开通试用服务。

![img](/images/console/voice_to_text_try.png)

试用期间，如需关闭服务，可点击 **取消订阅**。

## 正式开通

在 **语音转文字** 页面，点击 **正式开通**。在弹出的 **付款确认** 对话框中，确认付款信息后，点击 **立即支付**，即可开通服务。

![img](/images/console/voice_to_text_subscribe.png)

服务开通成功后，页面会提示 **开通成功**。

![img](/images/console/voice_to_text_subscribed.png)

开通后，如需取消订阅，可点击 **取消订阅**，并联系环信商务经理取消订阅。

![img](/images/console/voice_to_text_unsubscribe_manager.png)
