# Chat Room

After creating an app, you can configure the maximum number of chat rooms and extend the storage duration for chat room messages on [EasyIM Console](https://console.easyim.ai/user/login).

To open the chat room settings page, take the following steps:

1. Log in to [EasyIM Console](https://console.easyim.ai/user/login).
2. On the **Applications** page, click the App Key in the **AppKey-Dev** or **AppKey-Prod** column.
3. In the left navigation pane, select **Chat** > **Features**.
4. On the **Chat Room** page, configure chat room-related features.

![img](/images/console/basic_chat_room.png)

## Maximum number of chat rooms

The maximum number of chat rooms depends on your subscribed plan:

- Free: Supports up to 100 chat rooms. To increase the limit, click **Upgrade** to upgrade to the professional or flagship plan.
- Professional/flagship: Unlimited.

Note: Destroyed chat rooms do not count toward the limit.

![img](/images/console/basic_chatroom_count.png)

## Chat room message storage duration

EasyIM provides message cloud storage for chat rooms, including historical messages and roaming messages.

The cloud storage duration depends on your subscribed plan. For details, see [Plan Features](/product/product_package_feature.html). You can click **Upgrade** to extend the message cloud storage duration.

- Free: Supports up to 3 days. To increase the limit, click **Upgrade** to upgrade to the professional or flagship plan.
- Professional/flagship: Supports up to 7/90 days. To increase the limit, click **Buy Now** and pay separately to extend the storage duration.

For the fee details, see the [Pricing Policy](pricing_policy.html).
