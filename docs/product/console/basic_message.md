# 消息

创建应用后，你可以在 [环信控制台](https://console.easemob.com/user/login) 开通消息相关配置，包括消息云存储时长、已读回执、消息撤回、消息推送和消息举报等配置。

你可以按以下步骤打开消息配置页面：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **功能配置** > **基础功能**。
4. 在 **消息** 页面，开通消息相关配置。

![img](/images/console/basic_message.png)

##  消息云存储时长

即时通讯 IM 提供消息云存储功能，支持存储历史消息和漫游消息。

云存储时长与你订阅的套餐包有关，详见 [套餐包功能文档](/product/product_package_feature.html)。你可以单击 **升级** 延长消息云存储时长。
- 免费版：最大支持 3 天。若需提升上限，单击 **升级** 升级至专业版或旗舰版。
- 专业版/旗舰版：最大支持 7 天/90 天。若需提升上限，单击 **升级** 单独付费延长存储时长。
  每延长 30 天需支付 500 元。该功能支持叠加购买。例如，购买时选择了 10 份，表示消息云存储时长延长 300 天（30 天 x 10）。

![img](/images/console/basic_message_storage_duration.png)

## 单聊消息已读回执

单聊消息已读回执默认开通，你可以直接使用。

![img](/images/console/basic_message_receipt_single.png)

## 群聊消息已读回执

你可以根据当前的套餐包版本开通该服务：
 
- 免费版：点击 **立即升级** 升级到专业版或旗舰版，然后开通该功能。
- 专业版：点击 **立即购买** 单独购买该功能。
- 旗舰版：点击 **免费开通** 开通该功能。

![img](/images/console/basic_message_receipt_group.png)

## 消息撤回

对于各套餐包版本，使用消息撤回功能前，先点击 **免费开通**，然后点击 **设置** 设置客户端和 REST 端的消息撤回时长。默认支持撤回发送 2 分钟内的消息。你最多可以设置为 7 天。

## 图片消息缩略图

你可以点击 **编辑** 在弹出的对话框中配置图片消息缩略图 **压缩方式** 和 **压缩尺寸**：

- 压缩方式：可以按较小边压缩和按较长边压缩。
  - 按较小边压缩：选择原缩略图的宽度和高度中较小的一边按设置值进行等比压缩
  - 按较长边压缩：选择原缩略图的宽度和高度中较长的一边按设置值进行等比压缩
- 压缩尺寸：设置缩略图的宽度和高度，默认为 170 像素。

如果按该配置方法压缩后的图片大小大于原缩略图大小，则会按原缩略图保存。

## 离线推送高级功能

离线推送的高级功能包括 [推送通知方式](/document/android/push/push_notification_mode_dnd.html#推送通知方式)、[免打扰模式](/document/android/push/push_notification_mode_dnd.html#免打扰模式) 和 [推送模板](/document/android/push/push_display.html#使用推送模板)。

使用前离线推送高级功能，需点击 **免费开通** 开通该功能。

## 消息表情回复

消息表情可以直观地表达情绪，利用消息表情回复（Reaction）可以提升用户的使用体验。

你可以根据当前的套餐包版本开通该服务：

- 免费版/专业版：点击 **立即升级** 升级至旗舰版。
- 旗舰版：点击 **免费开通** 开通该服务。

![img](/images/console/basic_message_reaction.png)
