# 修改账号密码

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 鼠标悬停或单击右上角账号管理下拉菜单，选择 **账号信息**。
3. 在左侧导航栏中选择 **安全设置**。
4. 在右侧的 **安全设置** 页面中，在 **基本设置** 一栏中找到账号密码，点击 **修改**。
   
   ![img](/images/console/account_security_password_change.png)

5. 若开启了 [操作保护](account_security_operation_protection.html)，首先进行身份认证，例如，进行 MFA 验证。

    ![img](/images/console/account_security_password_auth.png)

6. 输入当前密码和新密码，点击 **保存**。

    ![img](/images/console/account_security_password_success.png)
