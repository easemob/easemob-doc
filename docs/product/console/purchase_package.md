# 管理套餐包

## 订阅套餐包

注册账号和创建应用后，你可以订阅即时通讯套餐包。**成功订阅的当天开始计费**。

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **服务开通** > **套餐购买**。
4. 选择套餐包，点击 **立即开通**。
5. 进入 **开通服务版本** 页面，查看各服务版本的功能详情，点击 **下一步**。

| 参数项                   | 描述                                          |
| :----------------------- | :-------------------------------------------- |
| 选择要开通服务的 Appkey | 请确认 App Key 是否选择正确，购买后无法修改。 |
| 请选择服务版本           | <br/> - 若 App Key 为免费版，可购买专业版或旗舰版，不可单独购买增值服务。<br/> - 若 App Key 为专业版，可购买旗舰版或单独购买增值服务。|
| 可选增值服务 | <br/> - 单个群成员数上限和单个用户可加入群组数上限：不支持叠加购买。例如，对于单个群成员数上限，旗舰版的免费额度为 3000人/群，若购买了 8000 人/群的增值服务，表示单个群成员上限配置提升至 8000 人/群，而非 110,000 人/群。<br/> - 消息云存储时长：支持叠加购买。例如，若购买时选择了 10 份，表示消息云存储时长延长 300 天（30 天 x 10）。 |

:::tip
该页面显示的预付费用仅包含基础费用，具体费用以每月账单为准。
:::

## 续费套餐包

所有版本的即时通讯套餐包均默认自动续订。套餐包到期时，你也可以在环信控制台重新下单 [订阅同版本或其他版本套餐](#订阅套餐包)。环信控制台暂不支持多笔订单订阅时长叠加。若你在套餐包未到期时创建了新订单，系统将自动为你关闭旧服务订单并退还剩余费用。

## 升级套餐包

应用创建后默认为免费版，可付费升级至专业版和旗舰版。

1. 登录 [环信控制台](https://console.easemob.com/user/login)，选择 **应用管理**，单击你的应用的 **操作** 栏中的 **管理**。
2. 在左侧导航栏，选择 **应用概览**。 
3. 在 **服务开通信息** 栏中点击 **调整套餐包** 升级套餐包。

升级成功后的当天开始按新版本计费，自动为你退还原套餐的剩余费用。原版本下订阅的所有增值服务会同时取消订阅并退还剩余费用。若你仍需要增值服务，请重新订阅。

:::tip
1. 如需降级或取消套餐包服务，请联系环信商务。
2. 套餐包降级时，目标版本不包含的功能会关闭。某些功能，例如回调，在关闭后会导致数据清除，无法恢复。
:::
