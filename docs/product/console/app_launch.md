# 上线应用

你可以将测试版应用上线为正式版应用。

## 上线前须知

正式版应用上线后，**AppName** 与 **Appkey** 将更新，测试版的业务数据不会同步，但基础功能配置会保留。

1. 上线前确认事项

- 当前应用仍为测试版，且尚未生成正式版。
- 已明确是否保留测试版中已开通的套餐、扩展功能与增值服务。

2. 服务上线规则

- **IM 免费版套餐**：若需上线，测试版须先开通实时音视频服务（享免费额度）。
- **实时音视频**：若测试版已开通，上线后自动开通该服务，并享有免费额度。
- **内容审核、消息翻译**：若测试版已订阅，上线后将不再适用免费额度，按正式版付费规则计费。
- **即时推送**：即使测试版已开通，上线后也不会自动保留，如需使用需单独订阅。

## 上线步骤

1. 登录 [环信控制台](https://console.easemob.com/user/login)，在页面上方选择 **应用管理**，或者在首页 **应用概览** 区域选择 **应用管理**。

![img](/images/console/app_overview.png)

2. 在 **应用列表** 页面，找到目标测试版应用，在 **操作** 栏点击 **申请上线**。

![img](/images/console/app_launch_apply.png)

3. 在 **申请上线** 对话框中填写正式版应用信息。

| 字段 | 是否必填 | 说明 |
| :--- | :--- | :--- |
| AppName | 是 | 正式版应用名称，仅支持小写字母、数字和连字符，长度不能超过 32 个字符。提交后不可修改。 |
| Appkey | 否 | 系统自动生成，无需填写。格式为 `OrgName + '#' + AppName`。 |
| 所在地 | 是 | **国内** 表示数据中心位于中国，**海外** 表示数据中心位于中国以外地区。 |
| 数据中心 | 是 | 数据中心取决于 **所在地**：<br/>**国内** 默认 **国内 2 区**，**海外** 默认 **新加坡 1 区**。<br/>如需其他数据中心，请联系环信商务。 |

填写完成后，确认费用信息并点击 **立即上线**。

- 上线过程通常需要 5—15 分钟。
- 上线期间无法修改测试版和正式版的应用信息及功能配置。
- 建议在收到短信或邮件通知后，再进行后续操作。

![img](/images/console/app_launch_confirm.png)

4. 系统弹出 **上线申请已提交** 对话框后，点击 **我知道了**。

![img](/images/console/app_launch_prompt.png)

5. 上线完成后，在应用列表中确认：

- **应用状态** 为 **已上线**。
- **AppKey-正式版** 栏中显示正式版 App Key。

![img](/images/console/app_launch_complete.png)

## 上线后处理

上线完成后，建议尽快完成以下操作：

1. 替换客户端 SDK 初始化配置中的正式版 `AppKey`。
2. 替换服务端请求地址中的 `{app_name}`，例如 `POST https://{host}/{org_name}/{app_name}/users`。
3. 检查发送前回调和发送后回调地址是否需要切换为正式环境地址。
4. 按正式环境重新准备用户、消息、好友、群组和聊天室等业务数据。原因是为保障数据安全，测试版中的业务数据**不会**同步到正式版。
