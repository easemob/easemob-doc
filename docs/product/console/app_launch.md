# 上线应用

对于在 [环信控制台](https://console.easemob.com/user/login) 上创建的测试版应用，你可以申请上线。

上线前后的应用的差别如下：

| 套餐类型     | 测试版    | 上线时   | 上线后         |
| :------- | :--------- | :----------- | :------------ |
| **免费版套餐包**        | 可使用免费版套餐包          | 只有订阅了实时音视频服务（免费版），免费版套餐包才能上线。   | 1. 上线后的应用，实时音频服务为订阅免费版。免费额度使用完毕，你可以选择升级套餐包。 2. 若测试版订阅了内容审核、消息翻译，上线时会有费用信息。上线后，这两种服务为付费版。 3. 即使测试版开通了消息推送，上线后即时推送服务默认仍关闭。若需使用该服务，你需要订阅。 4. 若测试版开通了基础功能，例如，好友关系检查、用户黑名单、消息撤回、服务端会话列表等服务，上线后这些功能仍为开通状态。 |
| **专业版/旗舰版套餐包** | 测试版为专业版/旗舰版套餐包 | 1. 若开通了其他扩展服务或增值服务，上线时会有费用相关信息。 2. 若测试版开通了基础功能，例如，好友关系检查、用户黑名单、消息撤回、服务端会话列表等服务，上线后这些功能仍为开通状态。 | 上线后的增值服务和扩展                                       |

## 操作步骤

1. 登录 [环信控制台](https://console.easemob.com/user/login) ，在页面上方选择 **应用管理** 或者在首页的 **应用概览** 区域选择 **应用管理**。
   
![img](/images/console/app_overview.png)

2. 在 **应用列表** 页面，点击目标测试应用的 **操作** 栏中的 **申请上线**。请注意已存在正式版应用的产品无法再次上线。// TODO：这句话没必要吧，已经有正式版的应用也没有

![img](/images/console/app_launch_apply.png)
   
3. 在弹出的 **申请上线** 对话框中，填写你的正式版应用的信息：

| 字段 | 是否必需 |说明 |
| :--- | :--- | :--- |
| AppName | 必填 | 应用名称，仅支持小写字母、数字和连字符，不能超过 32 个字符。不可重复，申请上线后不可修改。 |
| AppKey | 自动生成，无需填写。| 即时通讯 IM 分配给每个应用的唯一标识，格式为 `OrgName + '#' + AppName`，不可修改。<br>`OrgName`：注册账号后，环信控制台自动生成的组织的唯一标志。 |
| 所在地 | 必填。| <br>- **国内**：数据中心在中国。<br>- **海外**：数据中心在中国以外地区。 |
| 数据中心 | 必填。| <br>- 若 **所在地** 为 **国内**，数据中中心默认为 **国内2区**。<br>- 若 **所在地** 为 **海外**，数据中心默认为 **新加坡1区**。<br>- 若设置为其他数据中心，请联系环信商务。关于数据中心详情，请参见数据中心文档。 |
   
填写应用信息后，需确认正式版费用信息，点击 **立即上线**。测试版上线需持续 5—15 分钟，请耐心等待。上线期间无法修改测试版和正式版的应用信息和功能配置。上线成功后，我们将通过短信及邮件通知您，建议收到通知后再进行后续操作，避免影响业务正常运行。

- 若需修改或关闭套餐包和扩展功能的订阅，可参见 [订阅套餐包](purchase_package.html#订阅-升级套餐包)  或 [功能配置](basic_user.html) 中的说明。
- 若需关闭内容审核、消息翻译等增值服务的订阅，可参照 [开通增值服务](purchase_value_added.html) 中的说明。

![img](/images/console/app_launch_confirm.png)

4. 系统弹出 **上线申请已提交** 对话框，点击 **我知道了**。

![img](/images/console/app_launch_prompt.png)

5. 应用上线完毕后，应用列表中该应用的 **应用状态** 一栏为 **已上线**，**AppKey-正式版** 一栏中展示正式版应用的 App Key。

![img](/images/console/app_launch_complete.png)
  

## 上线注意事项

上线后，测试版基础功能配置将完整同步至正式版，但您仍需注意以下事项：

1. 正式版将创建和生成新的 AppName 和 AppKey，你需要进行如下替换：

- SDK 初始化时配置的 Appkey，详见 [初始化 SDK](/document/android/initialization.html)。
- 您调用服务端的请求 URL，如下所示中的 `{app_name}`。每个请求 URL 均包括 `app_name` 参数，详见服务端 API 概览。

   `POST https://{host}/{org_name}/{app_name}/users`

2. 正式版会同步发送前回调和发送后回调的地址。若在你的服务器中，正式环境的回调地址与测试环境回调地址不同，需及时替换。

3. 数据不同步

为保障数据安全，测试版的以下数据 **不会** 同步至正式版：
- 消息（漫游消息、历史消息）
- 用户
- 好友
- 群组
- 聊天室
