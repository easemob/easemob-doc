# 应用备案

若您的正式版应用所在地为国内，请及时将相关应用备案号如实填写至环信控制台。若未按要求登记备案号，环信有权依据相关规则终止服务。

按如下步骤进行应用备案：

1. 登录 [环信控制台](https://console.easemob.com/user/login)，在页面上方选择 **应用管理** 或者在 **首页** 的 **应用概览** 区域选择 **应用管理**。

![img](/images/console/app_mgmt_menu.png)

2. 在 **应用列表** 页面，点击目标测试应用的 **操作** 栏中的 **应用备案**。

![img](/images/console/app_file.png)

3. 在 **应用概览** 页面的 **应用备案信息** 栏中，点击 **编辑**，编辑应用备案信息。

![img](/images/console/app_file_edit.png)
