# 查询用户连接状态

你可以查询单个用户在最近三天内的设备连接状态。

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **运营管理 > 问题排查 > 用户连接状态查询**。
4. 输入用户 ID，设置查询时间，点击 **查询**。
5. 在 **用户状态历史** 栏中查看用户的设备连接状态。
