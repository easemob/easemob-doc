# 找回密码

你可以通过手机号或邮箱找回环信账号的登录密码。默认通过手机号找回密码。

## 通过手机号找回密码

1. 在环信控制台的登录页面，点击 **忘记密码**。
   
   ![img](/images/console/account_security_password_forget.png)
   
2. 在 **找回密码** 页面，填入手机号，点击获取验证码，拖动滑块，然后点击 **申请找回密码**。

   ![img](/images/console/account_security_password_retrieve.png)

3. 在 **重置密码** 页面，填写新密码，点击 **重置密码**。

   ![img](/images/console/account_security_password_reset.png)

4. 页面上方弹出重置成功的提示。你可以利用新密码登录控制台。 

   ![img](/images/console/account_security_password_retrieve_login.png)

## 通过邮箱找回密码

1. 在环信控制台的邮箱登录页面，点击 **忘记密码**。

   ![img](/images/console/account_security_password_forget.png)

2. 点击 **通过邮箱**，输入邮箱地址，点击 **申请找回密码**。
   
   页面上方提示前往邮箱查看。

   ![img](/images/console/account_security_password_retrieve_email.png)

   ![img](/images/console/account_security_password_retrieve_prompt.png)

3. 登录你的邮箱，点击重置密码链接。
   
   ![img](/images/console/account_security_password_retrieve_link.png)
   
4. 在重置密码页面输入新密码，确认新密码，然后点击 **重置密码**。

   ![img](/images/console/account_security_password_retrieve_reset_2.png)

5. 页面上方弹出重置成功的提示。你可以利用新密码登录控制台。 

   ![img](/images/console/account_security_password_retrieve_login.png)
