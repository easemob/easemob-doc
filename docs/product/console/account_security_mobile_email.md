# 修改手机号和邮箱

你可以修改环信账号绑定的手机号和邮箱。

## 修改手机号

你可以按照以下步骤修改环信账号绑定的手机号：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 鼠标悬停或单击右上角账号管理下拉菜单，选择 **账号信息**。
3. 在左侧导航栏中选择 **安全设置**。
4. 在右侧的 **安全设置** 页面中，在 **基本设置** 一栏中点击 **修改安全手机**。
   
   ![img](/images/console/account_security_mobile_change.png)
   
5. 进行身份认证。
   
   例如，进行 MFA 验证。

    ![img](/images/console/account_security_password_auth.png)  

6. 输入新手机号，填写验证码，点击 **确认修改**。

    ![img](/images/console/account_security_mobile_success.png)  


## 修改邮箱

你可以按照以下步骤修改环信账号绑定的手机号：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 鼠标悬停或单击右上角账号管理下拉菜单，选择 **账号信息**。
3. 在左侧导航栏中选择 **安全设置**。
4. 在右侧的 **安全设置** 页面中，在 **基本设置** 一栏中点击 **修改安全邮箱**。
   
   ![img](/images/console/account_security_email_change.png)

5. 进行身份认证。
   
   例如，进行 MFA 验证。

    ![img](/images/console/account_security_password_auth.png) 

6. 输入新邮箱，填写验证码，点击 **确认修改**。
   
   ![img](/images/console/account_security_email_success.png)
