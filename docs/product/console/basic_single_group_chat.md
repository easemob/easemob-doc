# One-to-One and Group Chat

After creating an app, you can configure one-to-one and group chat features in [EasyIM Console](https://console.easyim.ai/user/login), including message cloud storage duration, group message read receipts, and the maximum number of chat groups.

To open the one-to-one and group chat page, take the following steps:

1. Log in to [EasyIM Console](https://console.easyim.ai/user/login).
2. On the **Applications** page, click the App Key in the **AppKey-Dev** or **AppKey-Prod** column.
3. In the left navigation pane, select **Chat** > **Features**.
4. On the **1-on-1/Group Chat** page, configure one-to-one chat and group chat features.

![img](/images/console/basic_message.png)

## Message storage duration

EasyIM provides message cloud storage, including historical messages and roaming messages.

The cloud storage duration depends on your subscribed plan. For details, see [Plan Features](/product/product_package_feature.html). You can click **Upgrade** to extend the message cloud storage duration.

- Free: Supports up to 3 days. To increase the limit, click **Upgrade** to upgrade to the Professional or Flagship plan.
- Professional/Flagship: Supports up to 7/90 days. To increase the limit, click **Upgrade** and pay to extend the storage duration.

![img](/images/console/basic_message_storage_duration.png)

## One-to-one message read receipts

One-to-one message read receipts are enabled by default and can be used directly.

![img](/images/console/basic_message_receipt_single.png)

## Maximum number of chat groups

The maximum number of chat groups depends on your subscribed plan:

- Free: Supports up to 100 chat groups. To increase the limit, click **Upgrade** to upgrade to the Professional or Flagship plan.
- Professional/Flagship: Unlimited.

:::tip
Destroyed chat groups do not count toward the limit.
:::

![img](/images/console/basic_group_count.png)

## Group message read receipts

You can enable this service based on your current plan:

- Free: Click **Upgrade** to upgrade to the Professional or Flagship plan, and then enable the feature.
- Professional: Click **Buy Now** to purchase and enable the service.
- Flagship: Click **Free Activation** to enable the feature.

![img](/images/console/basic_message_receipt_group.png)

## Maximum members per chat group

The maximum number of members in a chat group depends on your subscribed plan:

- Free: Each chat group can have up to 100 users. To increase the limit, click **Upgrade** to upgrade to the Professional or Flagship plan.
- Professional/Flagship: Each chat group can have up to 300/3,000 users. You can pay to increase the limit.

![img](/images/console/basic_group_member_count.png)

## Maximum chat groups per user

The maximum number of chat groups a user can join depends on your subscribed plan:

- Free: Each user can join up to 100 chat groups. To increase the limit, click **Upgrade** to upgrade to the Professional or Flagship plan.
- Professional: Each user can join up to 600 chat groups. To increase the limit, click **Upgrade** to upgrade to the Flagship plan.
- Flagship: Each user can join up to 100,000 chat groups.

![img](/images/console/basic_group_per_user.png)
