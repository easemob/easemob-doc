# 解绑 MFA 设备

## 概述

若你不再需要 MFA 验证或更换 MFA 设备，可以解绑 MFA 设备。对于更换 MFA 设备，你在解绑 MFA 设备后，可以重新绑定新的 MFA 设备，详见 [绑定 MFA 设备](account_security_MFA_bind.html)。

:::tip
解绑 MFA 设备后，将自动关闭该账号在环信控制台的登录和操作保护中的 MFA 验证。
:::

## 解绑步骤

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 鼠标悬停或单击右上角账号管理下拉菜单，选择 **账号信息**。
3. 在左侧导航栏中选择 **安全设置**。
4. 在右侧的 **安全设置** 页面中，在 **基本设置** 一栏中点击 **解绑**。
5. 进行身份验证，输入 6 位动态验证码。
   **验证方式** 默认为 **MFA 验证**，你也可以使用手机验证码或邮箱验证码。

   ![img](/images/console/account_security_auth_unbind.png)

6. 确认解绑后，点击 **确定**，完成解绑。 

![img](/images/console/account_security_unbind_confirm.png)
