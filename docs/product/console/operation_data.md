# 实时信息概览

在 [环信控制台](https://console.easemob.com/user/login) 上，你可以查看运营数据：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **运营管理** > **运营数据**。

## 实时信息概览

你可以在该页面查看活跃用户数、活跃群组数、活跃聊天室数、当日登录设备数占比、消息量查询等应用的实时信息。

![img](/images/console/operation_data_overview.png)

## 用户管理

你可以在该页面查看本月峰值DAU、注册用户总数、今日活跃用户数和新增用户数以及一段时间内的用户数量的变化趋势。

![img](/images/console/operation_data_user.png)

## 群组管理

你可以在该页面查看群组数量统计，包括群组总数、今日活跃群组数、今日新增群组数、今日解散群组数。你还可以监测一段时间内群组数量的变化趋势，了解群组使用情况。

![img](/images/console/operation_data_group.png)

## 聊天室管理

你可以在该页面查看聊天室统计，包括聊天室总数、今日活跃聊天室数、今日新增聊天室数、今日解散聊天室数、今日聊天室同时在线人数。你还可以监测一段时间内聊天室数量的变化趋势，了解聊天室使用情况。

![img](/images/console/operation_data_chatroom.png)

## Server 数据

你可以在该页面查看超级社区的 Server 和 Channel 今日数量统计以及一段时间内的数量变化趋势，了解使用情况。

![img](/images/console/operation_data_server.png)

## 热点数据查询

在该页面的 **消息量查询** 栏中的 **查询类型** 中选择 **用户**、**群组** 或 **聊天室**，设置查询时间段，查看 TOP 50 的活跃用户、活跃群组、活跃聊天室的信息。

![img](/images/console/operation_data_hot.png)

点击右侧的 **详情** 可查看各类型消息的统计情况。

![img](/images/console/operation_data_hot_statistics.png)
