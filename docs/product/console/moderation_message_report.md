# 消息举报

环信即时通讯 IM 提供消息举报功能。你的用户可以在客户端举报违规消息。当服务器收到举报消息后，会将举报消息存储到数据库，并在 [环信控制台](https://console.easemob.com/user/login)展示。

开通 [消息举报](basic_message.html#消息举报) 功能后，你可以查看举报详情。

你可以按以下步骤打开 **消息举报** 页面：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **功能配置 > 增值功能 > 内容审核 > 消息举报**。
4. 在 **消息举报** 页面查看消息举报详情：
   - 查看一段时间内单聊、群聊或聊天室会话中指定用户处理措施相关的消息举报详情。
   - 查看一段时间内单聊、群聊或聊天室会话中单个被标记用户相关的消息举报详情。
   
   若用户在单聊、群组聊天或聊天室中发送了非法消息，app 管理员对用户的处理措施包括：
   - 封禁用户：对用户进行封禁。
   - 强制下线：将用户账号从所有登录的设备下线。
   - 加入黑名单：加入用户黑名单、群组黑名单或聊天室黑名单。
   - 删除用户：将用户从 app 中移除。
   - 撤回：撤回用户发送的消息。
   - 待审核：app 管理员尚未对发送非法消息的用户进行处理。
