# 实名认证

实名认证旨在验证你的账号的真实性和保障账号安全。完成账号注册和登录后，环信控制台 **首页** 会提醒你进行实名认证，否则你可能无法使用完整的即时通讯 IM 的服务。环信即时通讯 IM 的用户实名认证包含个人实名认证和企业实名认证。

## 使用限制  // TODO：请产品经理确认

- 请准确填写身份证信息，若 1 天内 3 次提交错误，则当天被系统限制提交。
- 完成个人实名认证后，可变更为企业实名认证。
- 完成企业实名认证后，不可变更为个人实名认证。
- 完成认证后的 30 天内，不可再更换同一认证类型的认证主体。

## 实名认证方式

个人实名认证和企业实名认证的区别如下：// TODO：请确认该表格的信息是否正确。

| 类型           | 企业实名认证                         | 个人实名认证                 |
| :------------- | :----------------------------------- | :--------------------------- |
| 认证所需时间   | 3 个工作日内完成认证                 | 30 秒完成认证                |
| 发票类型       | 可申请企业普通发票或企业专用发票     | 可申请个人发票或企业普通发票|
| 最大认证账号数 | 一个企业主体最多可实名认证 10 个账号 | 无限制                       |
| 账户最低余额   | 2000 元                              | 0 元                         |
| 欠费宽限期     | 30 天                                | 5 天                         |

## 个人实名认证

参考以下步骤完成个人实名认证：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
   
2. 环信控制台会弹出对话框，提示你进行实名认证。点击 **去认证**。或者，你可以点击页面右上角的账户名称，选择 **实名认证**。
   
   ![img](/images/console/real_name_personal_promot.png)

   ![img](/images/console/real_name_personal_menu.png)

3. 在 **实名认证** 页面，点击 **个人认证** 栏中的 **开始支付宝扫脸认证**。
   
   ![img](/images/console/real_name_personal_alipay.png)

4. 填写你的 **证件类型**、**姓名** 和 **证件号码**，然后点击 **下一步**。
   
   ![img](/images/console/real_name_personal_credential.png)

5. 打开支付宝，扫描二维码，进行身份验证。

   ![img](/images/console/real_name_personal_alipay_qrcode.png)
   
6. 支付宝扫脸验证通过后，环信控制台会弹出对话框，显示 **实名认证成功**。

   ![img](/images/console/real_name_personal_success.png)

7. 在 **实名认证** 页面， **个人认证** 栏中显示 **您已完成个人认证** 状态。 

   ![img](/images/console/real_name_personal_authed.png)

:::tip
个人实名认证支持的证件类型包括身份证、港澳居民来往内地通行证、台湾居民来往内地通行证、港澳居民居住证和台湾居民居住证。
:::

## 企业实名认证

### 对公打款认证

参考以下步骤完成企业实名认证：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
   
2. 环信控制台会弹出对话框，提示你进行实名认证。点击 **去认证**。或者，你可以点击页面右上角的账户名称，选择 **实名认证**。详见 [个人实名认证](#个人实名认证)。
   
3. 在 **实名认证** 页面，点击 **企业认证** 栏中的 **企业对公打款认证**。
   
   ![img](/images/console/real_name_enterprise_pay.png)

4. 填写企业基本信息，并在确认所有信息无误后，勾选下方的承诺信息，然后点击 **下一步**。
   - 企业信息：包括企业名称、社会统一信用代码、营业执照照片以及通讯地址。
   - 企业联系人信息：企业联系人姓名、身份证号以及手机号。

![img](/images/console/real_name_enterprise_pay_basics.png)

5. 填写企业银行信息：请填写企业银行相关信息，确认信息无误后点击 **下一步**。

![img](/images/console/real_name_enterprise_pay_account.png)

6. 确认企业打款信息：请在 **企业对公打款认证** 页面再次确认付款方与收款方信息。若发现付款方信息有误可以点击 **上一步**，确认信息无误后点击 **确认**。点击 **确认** 后，打开 **企业对公打款认证** 页面。

![img](/images/console/real_name_enterprise_pay_confirm.png)
   
7. 对公打款认证：
   - 提交企业实名认证信息后，你需要在 3 个工作日内用你提交的银行账户向环信指定银行账户转入 1 元以内的任意金额，用于核实你提交的企业认证信息。
   - 在该页面你会看到对公打款倒计时信息。打款前，你会在 **实名认证** 页面看到企业实名认证为 **认证中** 状态。
   - 若未能在 3 个工作日内打款，则企业实名认证将失败。**实名认证** 展示 **认证失败** 和 **失败原因：认证超时**。// TODO：
   - 企业实名认证状态存在一定延迟。若你已完成对公打款，但状态仍显示为 **认证中**，请耐心等待。

![img](/images/console/real_name_enterprise_paid.png)

8. 认证成功：如果你在 3 个工作日内转账成功且转账信息与你提交的认证信息一致，环信会通过你的企业认证申请，并将认证状态更新为 **您已完成企业认证**，企业可享受完整的服务功能。

![img](/images/console/real_name_enterprise_success.png)

:::tip
认证为企业账户后，请确保你的账户余额不少于 2000 元，否则环信将在 30 天后停止提供服务。

### 企业法人扫脸认证

参考以下步骤完成企业法人扫脸认证：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
   
2. 环信控制台会弹出对话框，提示你进行实名认证。点击 **去认证**。或者，你可以点击页面右上角的账户名称，选择 **实名认证**。详见 [个人实名认证](#个人实名认证)。
   
3. 在 **实名认证** 页面，点击 **企业认证** 栏中的 **法人扫脸认证**。
   
   ![img](/images/console/real_name_enterprise_face_recognition.png)

4. 填写企业基本信息，包括企业名称、社会统一信用代码、营业执照照片以及通讯地址，然后点击 **下一步**。
   
   ![img](/images/console/real_name_enterprise_basics.png)

5. 填写企业法人信息，包括法人姓名、身份证号以及手机号，然后点击 **下一步**。 

   ![img](/images/console/real_name_enterprise_personnel_basics.png)

6. 法定代表人打开支付宝，扫描二维码，进行身份验证，点击 **完成**。

请务必使用法定代表人的个人支付宝账号进行认证，不能使用企业支付宝。

 ![img](/images/console/real_name_enterprise_personnel_alipay.png)

7. 认证成功：认证完成后，环信会通过你的企业认证申请，并将认证状态更新为 **您已完成企业认证**，企业可享受完整的服务功能。

![img](/images/console/real_name_enterprise_personnel_success.png)
