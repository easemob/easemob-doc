# 管理应用

登录 [环信控制台](https://console.easemob.com/user/login)，在页面上方选择 **应用管理** 或者在 **首页** 的 **应用概览** 区域选择 **应用管理**。

![img](/images/console/app_mgmt_menu.png)

在应用列表中，单击指定应用的 **操作** 栏中的 **管理** 查看该应用的信息。

![img](/images/console/app_mgmt_list.png)

**应用概览** 页面包含开发配置信息、应用基本信息和服务开通信息。

![img](/images/console/app_info.png)

## 开发配置信息

**开发配置信息** 栏展示应用的 App Key、数据中心和域名配置。

- App Key：应用的唯一标识，由 **Org Name** 和 **App Name** 组成，生成后不允许修改。
- Client ID/Client Secret：
- 数据中心：分为国内和海外数据中心，详见 [数据中心文档](data_center.html)。
- 域名配置：环信为应用提供的 REST API 和 WebSocket 的请求域名。详见 [配置服务器域名文档](/document/applet/serverconfig.html)。

![img](/images/console/app_info_develop.png)

## 应用基本信息

**应用基本信息** 栏展示组织名称 **Org Name**、应用名称 **App Name**、产品名称和描述、资源消耗预警、当月费用统计以及 REST API 调用频率超限预警。

![img](/images/console/app_info_basic.png)

## 服务开通信息

**服务开通信息** 栏展示当前套餐版本和账户剩余费用，并且你可以调整套餐包、配置功能以及开通增值服务。

![img](/images/console/app_info_activation.png)
