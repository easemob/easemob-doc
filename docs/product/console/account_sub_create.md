# 子账号管理

你在环信控制台注册账号后，默认只有一个主账号，没有其他任何账号。

只有超级管理员账号才能创建管理员和开发者账号。管理员和开发者账号无权限创建账号。

## 创建子账号

1. 使用主账号登录 [环信控制台](https://console.easemob.com/user/login)。
2. 鼠标悬停或单击右上角账号管理下拉菜单，选择 **成员管理**。你可以可以选择 **账号信息**，然后在左侧导航栏选择 **成员管理**。
3. 在 **成员管理** 页面，点击 **添加成员**。
4. 在 **创建成员** 对话框，设置子账号信息，包括登录邮箱、登录密码、手机号码、角色权限和备注。
5. 点击 **创建** 保存子账号信息。

创建子账号后，需 [激活该账号](#激活子账号)，才能正常用于登录环信控制台进行应用配置和管理。

## 激活子账号

在 **成员管理** 页面，在子账号列表中，点击指定子账号的 **操作** 栏中的 **更多**，选择 **激活账号**。

在弹出的确认对话框中选择 **确认**，激活子账号。子账号激活后，该账号的 **账号激活** 列中为 **已激活**。

![img](/images/console/account_sub_activate.png)

![img](/images/console/account_sub_activate_confirm.png)

## 删除子账号

在 **成员管理** 页面，在子账号列表中，点击指定子账号的 **操作** 栏中的 **更多**，选择 **移除用户**。

在弹出的确认对话框中选择 **确认**，删除子账号。
