# 查询 IM 消息投递

你可以查询最近三天各类会话中指定用户通过 SDK 或 REST API 发送的消息的投递情况，或者指定消息 ID 的投递情况。

1. 登录 [环信控制台](https://console.easemob.com/user/login)。
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **运营管理 > 问题排查 > IM用户投递查询**。
4. 设置查询参数，点击 **查询**。
