# 开通增值服务

即时通讯 IM 的增值服务包括内容审核、即时推送、消息翻译和服务端 API 调用。你可以在 [环信控制台](https://console.easemob.com/user/login) 订阅增值服务。

按如下步骤打开 **增值服务** 页面：

1. 登录 [环信控制台](https://console.easemob.com/user/login)。 
2. 选择页面上方的 **应用管理**。在弹出的应用列表页面，单击你的应用的 **操作** 栏中的 **管理**。
3. 在左侧导航栏，选择 **服务开通** > **增值服务**。

## 前提条件

开通增值服务前，请确保你满足以下条件：
- 已注册了环信账号。
- 创建了至少一个应用。若未创建应用，请参考 [创建应用](app_create.html)。

## 内容审核

1. 选择 **内容审核** 页签，根据需要分别开通文本审核、图片审核、音频审核和视频审核服务。
2. 若需要关键词审核服务，可点击 **开通** 开通该服务。**注意开通该服务前，需先开通文本审核。**

开通后，你可以对内容审核服务进行配置，详见 [相关配置文档](moderation_rule_config.html)。

:::tip
1. 开通文本、图片和音视频审核服务需确保账户余额大于 288 元。首次开通，免费使用 7 天。
2. 如果使用自定义消息审核，需首先开通文本审核和图片审核，再联系商务开通自定义消息审核。// TODO：这样说对吗，我看 Console 上没有自定义消息审核开通。
3. 开通关键词审核需确保账户余额大于 1000 元。
:::

## 即时推送

选择 **即时推送** 页签，点击 **立即开通**。开通后，你可以对即时推送进行配置，详见 [相关配置文档](push_task_create.html)。

若注册用户超过 100，将自动开始计费。若仅需要测试推送功能，请使用全功能应用（DemoKey）测试。

## 消息翻译

选择 **消息翻译** 页签，点击 **立即开通** 开通消息翻译服务。

![img](/images/console/translation_activation.png)

服务开通后，你可以查看消息翻译额度、总使用量以及指定时间段内每天的使用量。

![img](/images/console/translation_statistics.png)

## 服务端 API 调用

选择 **服务端API调用** 页签。

专业版和旗舰版默认开通该服务。若你使用免费版，需要点击 **立即升级** 升级至专业版或旗舰版。

![img](/images/console/server_api_activation.png)

开通后，你可以点击指定接口的 **操作** 栏中的 **编辑**，在弹出的 **编辑服务API限流** 对话框中，上调接口的调用频率限制，阅读并同意《环信云服务购买协议》，然后点击 **确认购买**。

![img](/images/console/server_api_raiselimit.png)
