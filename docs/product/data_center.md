# 数据中心与加速节点

为满足不同业务覆盖区域的部署需求，环信提供多种数据中心和加速节点选择。你可以根据终端用户分布、业务部署区域以及合规要求，选择合适的数据中心和网络加速方案。

目前环信支持以下数据中心和加速节点。

## 数据中心与加速节点概览

### 数据中心

| 类型         | 名称                                           |
| :----------- | :--------------------------------------------- |
| 国内数据中心 | 国内 1 区、国内 2 区、国内 VIP 区。              |
| 海外数据中心 | 新加坡 1 区、新加坡 2 区、美东 1 区、德国 2 区。 |

数据中心的用途说明如下：

| 名称                     | 用途                                                       |
| :----------------------- | :--------------------------------------------------------- |
| 国内 1 区、国内 2 区     | 环信 IM 社区版、企业版、旗舰版、免费版和专业版客户所在集群。 |
| 国内 VIP 区              | 尊享版客户及单独购买 VIP 集群服务的客户所在集群。            |
| 新加坡 1 区、新加坡 2 区 | 环信海外客户所在集群。                                       |
| 美东 1 区                | 环信海外客户所在集群。                                       |
| 德国 2 区                | 环信海外客户所在集群。                                       |

### 加速节点

| 类型         | 名称 |
| :----------- | :--- |
| 海外加速节点 | 全球 |

### 数据中心选择与查看

你可以根据终端用户的主要分布区域选择数据中心：

- 如果绝大部分终端用户位于中国大陆，建议选择国内数据中心。
- 如果绝大部分终端用户位于海外，建议选择海外数据中心。
- 如果终端用户同时分布在国内和海外，且跨国通信频繁，建议在已有数据中心基础上开通海外加速服务。
- 如果你需要专属资源或更高规格的集群服务，可选择国内 VIP 区或联系商务购买相应服务。

在环信控制台创建应用时：
- 国内数据中心默认为 **国内 2 区**。若要使用其他数据中心，需要联系环信商务。
- 海外数据中心默认为 **新加坡 1 区**，也可选择 **美东1区** 或 **德国2区**。若要使用新加坡2区，需要联系环信商务。

你可以在环信控制台的 **应用概览** 页面查看应用所在的数据中心及服务器域名。

已分配应用专属域名时，控制台展示使用应用专属域名的 REST API 和 WebSocket 地址；未分配应用专属域名时，展示使用集群域名的地址。具体入口和展示规则见 [查看应用服务器域名](/product/console/app_manage.html#查看应用服务器域名)。

## 国内数据中心

### 应用场景

适用于绝大部分终端用户位于国内的应用。

### 集成说明

创建应用时，国内数据中心默认为 **国内 2 区**。

国内 2 区的应用使用的服务器域名分为两类：

- **集群域名**：同一集群内的应用共用，部分历史应用仍使用此类域名。
- **应用专属域名**：按应用分配，每个应用使用自己的域名。应用专属域名功能上线后，新创建的应用使用此类域名。

各国内数据中心的具体 REST API 和 WebSocket 地址，请从当前应用的控制台页面获取，详见 [查看应用服务器域名](/product/console/app_manage.html#查看应用服务器域名)。请以当前应用页面展示的地址为准，不要仅根据数据中心名称确定域名。

[小程序还需在平台后台添加对应的合法域名](/document/web/serverconfig.html)。

## 海外数据中心

### 应用场景

适用于绝大部分终端用户位于海外的应用。

### 集成说明

海外数据中心默认为 **新加坡 1 区**。

各海外数据中心的具体 REST API 和 WebSocket 地址，请从当前应用的控制台页面获取，详见 [查看应用服务器域名](/product/console/app_manage.html#查看应用服务器域名)。使用应用专属域名时，应使用当前应用的地址；使用集群域名时，应使用当前应用对应的集群地址。

[小程序还需在平台后台添加对应的合法域名](/document/web/serverconfig.html)。

:::tip
根据海外数据隐私保护协议规定，选择新加坡 1 区、新加坡 2 区、美东 1 区或德国 2 区后，不可迁移至其他集群。
:::

## 海外加速服务

### 应用场景

适用于部分终端用户位于国内、部分终端用户位于海外，且跨国用户之间需要进行消息通信的场景。

### 使用说明

环信会根据应用所在数据中心及终端用户分布，为你开通所需的网络加速节点。

加速节点默认带宽为 **1 Mbps**，你可以根据实际流量需求配置更合适的带宽。  

如需开通相关服务，请联系你的商务经理。

### 节点分布

| :----------- | :--- |
| 海外加速节点 | 全球 |

## 常见问题

### 1. 创建应用时为何看不到某些数据中心？

环信控制台默认仅开放部分常用数据中心供选择。如果你需要使用其他数据中心，例如国内 VIP 区或其他海外集群，请联系环信商务申请开通。

### 2. 如何确认应用使用的数据中心？

你可以登录环信控制台，在 **应用概览** 页面查看应用所在数据中心。具体服务器域名的查看方式见 [查看应用服务器域名](/product/console/app_manage.html#查看应用服务器域名)。

### 3. 国内 1 区和国内 2 区有什么区别？

国内 1 区和国内 2 区在服务能力上没有区别。要使用国内 1 区需联系环信商务申请开通。

### 4. 海外数据中心之间可以迁移吗？

根据海外数据隐私保护协议规定，选择新加坡 1 区、新加坡 2 区、美东 1 区或德国 2 区后，不可迁移至其他海外集群。

### 5. 什么情况下需要开通海外加速服务？

如果你的终端用户同时分布在国内和海外，且跨国用户之间存在频繁消息通信需求，建议开通海外加速服务，以提升跨区域访问体验。

### 6. 海外加速节点默认带宽及可否调整？

海外加速节点默认带宽为 **1 Mbps**。如果业务流量更高，可以根据实际需求配置更高带宽，具体请联系环信商务。

### 7. 各端是否需按数据中心配置不同地址？

请以当前应用的控制台页面展示值为准。使用应用专属域名时，各应用使用自己的域名，即使位于同一数据中心，域名也可能不同；使用集群域名时，同一集群内的应用共用域名。详见 [查看应用服务器域名](/product/console/app_manage.html#查看应用服务器域名)。
