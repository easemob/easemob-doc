# 如何配置服务器域名

<Toc />

在生产环境中，微信小程序必须配置合法的服务器域名，否则将无法正常访问相关服务。本文介绍如何在微信小程序管理后台中配置服务器域名，具体步骤如下。

1. 打开 [微信公众平台官网](https://mp.weixin.qq.com/)，登录微信小程序账号，进入小程序管理后台首页。
2. 在左侧菜单中找到 **</> 开发** 模块。

![img](/images/applet/config1.png)

3. 进入 **</> 开发** 模块，点击 **开发管理**，然后在 **开发设置** 中找到 **服务器域名** 配置项。

![img](/images/applet/config2.png)

4. 如果是首次配置服务器域名，页面会显示 **开始配置** 按钮。点击该按钮进入配置流程。

![img](/images/applet/config3.png)

5. 在配置服务器信息前，需要先完成身份确认。请由管理员使用微信扫码进行身份认证。

![img](/images/applet/config4.png)

6. 完成管理员身份认证后，进入 **配置服务器信息** 页面，在 **socket 合法域名** 字段中填写服务器域名。

![img](/images/applet/config5.png)

7. 登录环信控制台获取 socket 域名，进入 **应用概览** 页面，即可看到如图的域名展示。

:::tip
抖音小程序、QQ 小程序、百度小程序以及 uni-app 全平台的域名配置规则与微信小程序一致，使用微信小程序栏中的域名即可。
:::

![img](/images/applet/config6.png)

8. 填写域名信息后，点击 **保存并提交** 按钮，完成配置。

![img](/images/applet/config7.png)

9. 配置完成后，如需修改或删除服务器域名，可再次进入 **</> 开发** 模块，打开 **服务器域名** 设置页面进行操作。
