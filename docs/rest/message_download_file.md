# Download a File

This article describes how to call the REST API to download an image, voice, video, or another type of file from the EasyIM server.

## Feature overview

- Download images, voice files, video files, or other types of files.
- Restrict file access. If file access was restricted when the file was uploaded by setting `restrict-access` to `true`, the download request header must include the `share-secret` returned in the upload response and the token of the currently logged-in user.
- The file ID (`file_uuid`), file URL (`uri`), and file access key (`share-secret`) returned in the [Upload a file](message_upload_file.html#response-body-fields) response can be used to construct attachment messages and download attachments. For details, see [Attachment message sending workflow](message_single.html#attachment-message-sending-workflow) and [Download an attachment](message_download_file.html). If restricted access was enabled when the file was uploaded by setting `restrict-access=true`, you must pass `share-secret` when downloading either the original file or its thumbnail.

## Call frequency limit

100 requests per second per App Key
  
## Request URL

```http
GET https://{host}/{org_name}/{app_name}/chatfiles/{file_uuid}
```

| Parameter        | Type   | Required | Description                      |
| :---------- | :----- | :------- | :------------------------ |
| `file_uuid` | String | Yes       | The UUID generated by the server for the file. You can obtain the file UUID from the response of the [Upload a file](message_upload_file.html#response-body-fields) API. |

For descriptions of the parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

The following example downloads an image:

```bash
# Replace <YourToken> with your user token or an app token generated on your server 

curl -X GET 'https://XXXX/XXXX/XXXX/chatfiles/7f456bf0-XXXX-XXXX-b630-777db304f26c'-o /Users/test/easemob/image/image.JPG    \
-H 'Accept: application/octet-stream'    \
-H 'Authorization: Bearer <YourToken>'     \
-H 'share-secret: f0Vr-uyyEeiHpHmsu53XXXXXXXXZYgyLkdfsZ4xo2Z0cSBnB' 
```

:::tip
In the preceding request example, `/Users/test/easemob/image/image.JPG` is the local file path for EasyIM. Replace it with your own file path. Otherwise, the request fails.
:::

## Request header fields

For descriptions of the `Accept` and `Authorization` fields, see [Request header field descriptions](overview.html#request-header-fields).

| Parameter            | Type   | Required | Description           |
| :-------------- | :----- | :------- | :--------------- |
| `share-secret`  | String | No       | The file access key. If access was restricted when the file was uploaded, this key is required to download the file. After successfully uploading the file, obtain the key from the response body of [Upload a file](message_upload_file.html#response-body-fields). |

## Response example

```json
{
  // Voice/image file content
}
```

## Response body fields

If the returned HTTP status code is `200`, the request is successful. For the parameters and their descriptions, see [Upload a file](message_upload_file.html).

If the returned HTTP status code is not `200`, the request fails. See [Response status codes](error.html) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and may return the following error codes:

| HTTP status code | Error type               | Error message                  | Possible cause    | Recommendation      |
|:---------|:-------------------|:----------------------|:--------|:----------|
| 404      | entity_not_found | file may not exists | The specified `file_uuid` does not exist. | Enter the correct path parameter `file_uuid`. |
| 404      | file_expired | file xxxxx is expired | The file has expired. | By default, message attachments such as images, audio, video, and other files can be stored for 7 days. To increase this limit, contact the EasyIM business manager.  |

For other errors and their possible causes, see [Response status codes](error.html).
