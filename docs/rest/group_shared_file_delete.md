# Delete a Chat Group Shared File

## Feature overview

- Delete a chat group shared file by chat group ID and file ID (`file_id`).
- Obtain the file ID from the response of the [Download a Chat Group Shared File](group_shared_file_download.html) API.
- Deleting a chat group shared file triggers a post-delivery callback. For details, see [Chat Group Shared File Deleted](callback_group_shared_file.html#chat-group-shared-file-deletion-event).

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
DELETE https://{host}/{org_name}/{app_name}/chatgroups/{group_id}/share_files/{file_id}
```

For details about other parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X DELETE 'https://XXXX/XXXX/XXXX/chatgroups/6XXXX7/share_files/b30XXXX4f'  \
-H 'Content-Type: application/json'  \
-H 'Accept: application/json'  \
-H 'Authorization: Bearer <YourAppToken>'  \
```

## Request header fields

For descriptions of the `Content-Type`, `Accept`, and `Authorization` fields, see [Request header fields](overview.html#request-header-fields).

## Response example

{

  "organization": "XXXX",

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The `data` field in the response body is described below:

| Field            | Type   | Description         |
| :-------------- | :----- | :-------------------- |
| `data.group_id` | String | Chat group ID.                                                                     |
| `data.file_id`  | String | Chat group shared file ID. This parameter is required to download the shared file. |
| `data.result`   | Bool   | Whether the chat group shared file was deleted successfully: <br/> - `true`: The file was deleted; <br/> - `false`: The file was not deleted. |

The descriptions of other fields are shown in the following table:

| Field              | Type   | Description                                                    |
| :---------------- | :----- | :------------------------------------------------------ |
| `action`          | String | Request method.       |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `uri`             | String | Request URL.            |
| `entities`        | JSON Array   | The response entity.      |
| `timestamp`       | Long   | Unix timestamp in milliseconds.     |
| `duration`        | Int    | The length of time from sending the request to the response, in milliseconds.    |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `applicationName` | String | App name entered when you created the app in the EasyIM Console, identical to the `app_name` request parameter. |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |
| 404     | RestGroupFeignException | grpID XX does not exist! | The chat group does not exist. | Use a valid chat group ID. |

For other errors, see [Response status codes](error.html) for possible causes.
