# Add a Chat Group Member

## Feature overview

- Add one chat group member at a time.
- If the user is already a chat group member, the request fails with error 403.
- After adding a single chat group member, the server sends system notifications to the chat group members by default. You can set whether to send this notification.
- Adding a chat group member triggers a post-delivery callback. For details, see [User Invited to Join a Chat Group](callback_group_room_join.html#invite-a-user-to-join-a-chat-group).
 
## Call frequency limit

100 calls/second/App Key

## Request URL

```http
POST https://{host}/{org_name}/{app_name}/chatgroups/{group_id}/users/{username}?need_notify=false
```

| Parameter            | Type   | Required | Description       |
| :-------------- | :----- | :------- | :------------ |
| `group_id`  | Int    |  Yes       | Chat group ID. |
| `username` | String | Yes       | The user ID to add as a chat group member. |
| `need_notify` | Bool   | No       | Whether to send system notifications to chat group members after adding chat group members. <br/> - (Default) `true`: Yes; <br/> - `false`: No.   |

For details about other parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X POST 'https://XXXX/XXXX/XXXX/chatgroups/66XXXX85/users/user4?need_notify=false'  \
-H 'Content-Type: application/json'  \
-H 'Accept: application/json'   \
-H 'Authorization: Bearer <YourAppToken>' 
```

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The `data` field in the response body is described below:

| Field           | Type   | Description                                                                  |
| :------------- | :----- | :-------------------------------------------------------------------- |
| `data.result`  | Bool   | Whether the member was added successfully: <br/> - `true`: The member was added. <br/> - `false`: The member was not added. |
| `data.groupid` | String | Chat group ID.                                                             |
| `data.action`  | String | The operation performed. In this response, the value of this field is `add_member`, which means adding a chat group member. |
| `data.user`    | String | The user ID that was added. |

The other fields are described below:

| Field          | Type | Description                                                                              |
| :------------ | :--- | :-------------------------------------------------------------------------------- |
| `action`          | String | Request method. |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `uri`             | String | Request URL. |
| `entities`        | JSON Array   | Response entities. |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `applicationName` | String | App name entered when you created the app in the Easemob Console, identical to the `app_name` request parameter. |

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |
| 403     | forbidden_op | can not join this group, reason:user: XX already in group: XX\n | The user is already in the chat group. | Do not add the same user again. |
| 404     | resource_not_found | grpID XX does not exist! | The chat group does not exist. | Use a valid chat group ID. |
| 404     | resource_not_found | username XX doesn't exist! | The user to add does not exist. | Specify an existing user ID in `username`.|
| 403     | exceed_limit | user XX has joined too many groups! | The user has reached the limit on joined chat groups. | Leave unused chat groups or increase the limit in the [Easemob Console](/product/console/basic_conversation_group_chatroom.html#maximum-number-of-chat-groups-a-user-can-join). |

For other errors, see [Response status codes](error.html) for possible causes.
