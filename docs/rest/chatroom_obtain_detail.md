# Retrieve Chat Room Details

## Feature overview

Retrieves details of one or more chat rooms.

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
GET https://{host}/{org_name}/{app_name}/chatrooms/{chatroom_id}
```

| Parameter           | Type   | Required | Description                                |
| :------------- | :----- | :------- | :---------------------------------- |
| `chatroom_id` | String | Yes       | Chat room ID. |

For instructions on other parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X GET 'https://XXXX/XXXX/XXXX/chatrooms/662XXXX13' \ 
-H 'Accept: application/json'  \
-H 'Authorization: Bearer <YourAppToken>' 
```

## Request header fields

For details about the `Accept` and `Authorization` fields, see [Request header fields](overview.html#request-header-fields).

## Response example

```json
{
  "data": {
    "id": "662XXXX13",
    "name": "testchatroom1",
    "description": "test",
    "membersonly": false,
    "allowinvites": false,
    "maxusers": 200,
    "owner": "user1",
    "created": 1542542951527,
    "custom": "",
    "affiliations_count": 2,
    "affiliations": [
      {
        "member": "user2"
      },
      {
        "owner": "user1"
      }
    ],
    "public": true,
    "mute": false
  }
}
```

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The `data` parameter in the response body is described below:

| Field                      | Type   | Description      |
| :------------------------ | :----- | :----------------- |
| `data`               | JSON | Details of the retrieved data.    |
| - `id`                 | String | Chat room ID, which uniquely identifies the chat room and is generated by the EasyIM server.    |
| - `name`               | String | Chat room name.    |
| - `description`        | String | Chat room description.    |
| - `membersonly`        | Bool   | Whether joining the chat room requires approval from the chat room owner or a chat room admin:<br/> - `true`: Yes.<br/> - `false`: No.    |
| - `allowinvites`       | Bool   | Whether chat room members can invite other users to join the chat room:<br/> - `true`: Chat room members can invite others to join the chat room.<br/> - `false`: Only the chat room owner and admins can invite others to join the chat room. |
| - `maxusers`           | Int    | Maximum number of chat room members, set when the chat room is created.                                                                                                                            |
| - `owner`              | String | User ID of the chat room owner. Example: {"owner": "user1"}.                                                                                                               |
| - `created`            | Long   | Chat room creation time as a Unix timestamp in milliseconds.                                                                                                                       |
| - `custom`             | String | Chat room extension information. |
| - `affiliations_count` | Int    | Current total number of chat room members. |
| - `affiliations`       | Array  | List of current chat room members, including the chat room owner and members (including chat room admins). Example: "affiliations":[{"owner": "user1"},{"member":"user2"},{"member":"user3"}]. The server does not sort members, so the returned member list is not guaranteed to be ordered.|
| - `public`             | Bool   | Reserved field. You do not need to pay attention to it. |
| - `mute` | Bool | Whether all members are muted:<br/> - `true`: Yes.<br/> - `false`: No. |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |
| 404     | service_resource_not_found | do not find this group:XX | The chat room ID does not exist. | Specify a valid chat room ID. |

For other errors, see [Response status codes](error.html) for possible causes.
