# Retrieve Chat Rooms Joined by a User

## Feature overview

Retrieves, by page, the chat rooms joined by a user based on the user ID.

## Call frequency limit

50 calls/second/App Key

## Request URL

```http
GET https://{host}/{org_name}/{app_name}/users/{username}/joined_chatrooms?pagenum={N}&pagesize={N}
```

| Parameter       | Type | Required | Description                                    |
| :--------- | :--- | :------- | :-------------------------------------- |
| `username`  | String  | Yes       | User ID. The API retrieves chat rooms joined by this user.                  |
| `pagenum`  | Int  | No       | Current page number. The default value is 1.                  |
| `pagesize` | Int  | No       | Number of chat rooms returned per page. The value range is [1,1000], and the default value is `1000`. This parameter is required only for paginated retrieval. If the specified value exceeds `1000`, 1000 chat rooms are returned. |

:::tip
If neither `pagenum` nor `pagesize` is specified, the server returns the 500 chat rooms that the user most recently joined.
:::

For details about other parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server
curl -X GET 'https://XXXX/XXXX/XXXX/users/user1/joined_chatrooms?pagenum=1&pagesize=10' \ 
-H 'Accept: application/json'   \  
-H 'Authorization: Bearer <YourAppToken>' 
```

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The `data` parameter in the response body is described below:

| Field        | Type   | Description                                                      |
| :---------- | :----- | :-------------------------------------------------------- |
| `data` | JSON Array | Chat room details. |
|  - `id`   | String | Chat room ID, which uniquely identifies the chat room and is generated by the EasyIM server. |
|  - `name` | String | Chat room name. The maximum length is 128 characters.                         |

The other fields in the response body are described below:

| Parameter              | Type   | Description                                                                           |
| :---------------- | :----- | :----------------------------------------------------------------------------- |
| `action`          | String | Request method. |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `applicationName` | String | App name entered when you created the app in the EasyIM Console, identical to the `app_name` request parameter. |
| `count` | String | Number of chat rooms retrieved. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `entities`        | JSON Array   | The response entity.      |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `params`        | JSON | Query parameters.  |
|  - `pagesize`        | Array | Expected number of chat rooms returned per page.  |
|  - `pagenum`        | Array | Current page number.  |
| `properties`      | String | Response properties.                                                                     |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `uri`            | String | Request URL.                              |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |

For other errors, see [Response status codes](error.html) for possible causes.
