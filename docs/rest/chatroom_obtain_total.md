# Retrieve Chat Rooms in an App

## Feature overview

Retrieves, by page, the list of chat rooms in an app and their information, including the chat room ID, chat room name, user ID of the chat room creator, and current total number of chat room members (including the chat room creator).

## Call frequency limit

50 calls/second/App Key

## Request URL

```http
GET https://{host}/{org_name}/{app_name}/chatrooms?limit={N}&cursor={cursor}
```

| Parameter     | Type   | Required | Description                                                                                      |
| :------- | :----- | :------- | :---------------------------------------------------------------------------------------- |
| `limit`  | Int    | No       | Expected number of chat rooms returned each time. The value range is [1,1000], and the default value is `10`. This parameter is required only for paginated retrieval. If the specified value exceeds `1000`, 1000 chat rooms are returned. |
| `cursor` | String | No       | Starting position for the data query. This parameter is required only for paginated retrieval.   |

:::tip
If neither `limit` nor `cursor` is set in the request, the EasyIM server returns the first 10 chat rooms on the first page of the chat room list.
:::

For details about the parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X GET 'https://XXXX/XXXX/XXXX/chatrooms?limit=10' \
-H 'Authorization: Bearer <YourAppToken>'
```

## Request header fields

For a description of the `Authorization` field, see [Request header fields](overview.html#request-header-fields).

## Response example

```json
{
  "data": {
    "id": "662XXXX13",
    "name": "testchatroom1",
    "owner": "user1",
    "affiliations_count": 2
  }
}
```

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The `data` field in the response body is described below:

| Field                      | Type   | Description                                                      |
| :------------------------ | :----- | :-------------------------------------------------------- |
| `data`                 | JSON | Details of the retrieved data. |
| - `id`                 | String | Chat room ID, which uniquely identifies the chat room and is generated by the EasyIM server. |
| - `name`               | String | Chat room name.                                              |
| - `owner`              | String | User ID of the chat room creator. Example: {"owner": "user1"}.         |
| - `affiliations_count` | Int    | Current total number of chat room members, including the chat room creator.                  |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |

For other errors, see [Response status codes](error.html) for possible causes.
