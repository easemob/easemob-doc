# Set Global Mute for a User

## Feature overview

- Set global mute for one-to-one, group, and chat room messages for a user ID.
- After the setting succeeds, the user cannot send messages in the corresponding one-to-one chats, chat groups, or chat rooms, and the [pre-delivery webhook](callback_presending.html) is not triggered.
- You can set a mute duration. When it expires, the server automatically unmutes the user and restores their permission to send messages.
- Permanent mute is supported for one-to-one chats, chat groups, and chat rooms.

## Feature activation

Before using global user mute, activate it in the EasyIM Console. For details, see [EasyIM Console documentation](/product/console/basic_user.html#global-user-mute).

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
POST https://{host}/{org_name}/{app_name}/mutes
```

For details about the parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X POST 'https://XXXX/XXXX/XXXX/mutes' \
-H 'Authorization: Bearer <YourAppToken>' \
-H 'Content-Type: application/json' \
-H 'Accept: application/json'  \
-d '{
    "username": "zs1",
    "chat": 100,
    "groupchat": 100,
    "chatroom": 100
}'
```

## Request header fields

For details about the `Content-Type`, `Accept`, and `Authorization` fields, see [Request header fields](overview.html#request-header-fields).

## Request body fields

| Parameter        | Type   | Required | Description   |
| :---------- | :----- | :------- | :----------------------- |
| `username`  | String | Yes       | User ID for which global mute is to be set. |
| `chat`      | Int    | No       | One-to-one chat mute duration in seconds. The maximum is `2147483647`.<br/> - > `0`: One-to-one chat mute duration for the user ID.<br/> - `0`: Cancel one-to-one chat mute for the user.<br/> - `-1`: Permanently mute the user in one-to-one chats.<br/> - Other negative values are invalid. |
| `groupchat` | Int    | No       | Chat group mute duration in seconds. The rules are the same as for one-to-one chat mute. |
| `chatroom`  | Int    | No       | Chat room mute duration in seconds. The rules are the same as for one-to-one chat mute. |

:::tip
The `chat`, `groupchat`, and `chatroom` parameters are all optional. If all are omitted, the request succeeds but no mute action is performed.
:::

## Response example

```json
{
  "path": "/mutes",
  "uri": "https://XXXX/XXXX/XXXX/mutes",
  "timestamp": 1631609754727,
  "organization": "XXXX",
  "application": "357169f0-XXXX-XXXX-9b3a-f1af649cc48d",
  "action": "post",
  "data": {
    "result": "ok"
  },
  "duration": 74,
  "applicationName": "XXXX"
}
```

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The response body contains the following fields:

| Field          | Type   | Description                                          |
| :------------ | :----- | :-------------------------------------------- |
| `data`               | JSON   | Global mute result. |
| `data.result` | String | Whether global mute was set successfully for the user. `ok` indicates success. |

The other fields in the response body are described below:

| Field           | Type   | Description                        |
| :------------- | :----- | :---------------------- |
| `path`               | String | Request path, which is part of the request URL and does not require your attention. |
| `uri`             | String | Request URL. |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `action`          | String | Request method. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `applicationName` | String | App name entered when you created the app in the EasyIM Console, identical to the `app_name` request parameter. |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code | Error type | Error message | Possible cause | Recommendation |
| :----- | :---------- | :-------- | :------------------| :------------------------|
| 400         | required_property_not_found        | Entity user requires a property named username    | The user does not exist. | Register the user first or verify the username. |
| 401         | unauthorized                       | Unable to authenticate (OAuth)   | The token is invalid, expired, or incorrect. | Use a new token. |
| 403 | forbidden_op | user_mute is not used for this app | The global mute feature is not activated. | Activate this feature in the EasyIM Console. For details, see [EasyIM Console documentation](/product/console/basic_user.html#global-user-mute). |
| 404         | organization_application_not_found | Could not find application for XXX/XXX from URI: XXX/XXX/users | The App Key does not exist. | Verify `orgName` and `appName`, or [create an app](/product/console/app_create.html). |

For other errors, see [Error codes](error.html) for possible causes.
