# Upload a Chat Group Shared File

## Feature overview

- Upload a shared file to a specified chat group.
- The uploaded file cannot exceed 10 MB.
- After retrieving shared files in the specified chat group by page, use the file ID (`file_id`) returned in the response to call the [Download a Chat Group Shared File](group_shared_file_download.html) or [Delete a Chat Group Shared File](group_shared_file_delete.html) API.
- Uploading a chat group shared file triggers a post-delivery callback. For details, see [Chat Group Shared File Uploaded](callback_group_shared_file.html#chat-group-shared-file-upload-event).

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
POST https://{host}/{org_name}/{app_name}/chatgroups/{group_id}/share_files
```

For details about other parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X POST 'https://XXXX/XXXX/XXXX/chatgroups/66021836783617/share_files'   \
-H 'Accept: application/json'  \
-H 'Authorization: Bearer <YourAppToken>'  \
-H 'Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW'  \
-F file=@/Users/test/image/IMG_3.JPG
```

## Request header fields

| Parameter              | Type   | Required | Description            |
| :---------------- | :----- | :------- | :----------------------------- |
| `Content-Type`    | String | Yes       | Content type. Set this field to `multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW`. |
| `file`            | String | Yes       | The local path of the file to be uploaded.      |

For details about the `Accept` and `Authorization` fields, see [Request header fields](overview.html#request-header-fields).

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The response body contains the following fields:

| Field             | Type   | Description                                                       |
| :--------------- | :----- | :--------------------------------------------------------- |
| `data.file_url`  | String | URL where the chat group shared file is stored on the EasyIM server. |
| `data.group_id`  | String | Chat group ID.                                                  |
| `data.file_name` | String | The name of the chat group shared file.                                         |
| `data.created`   | Long   | Time when the chat group shared file was uploaded. |
| `data.file_id`   | String | Chat group shared file ID, which can be used to download and delete shared files.              |
| `data.file_size` | Long   | The size of the chat group shared file, in bytes.                             |

The descriptions of other fields are shown in the following table:

| Parameter              | Type   | Description        |
| :---------------- | :----- | :----------- |
| `action`          | String | Request method.   |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `uri`             | String | Request URL. |
| `entities`        | JSON Array   | Response entities. |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `applicationName` | String | App name entered when you created the app in the EasyIM Console, identical to the `app_name` request parameter. |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |
| 404     | RestGroupFeignException | grpID XX does not exist! | The chat group does not exist. | Use a valid chat group ID. |
| 400     | IllegalArgumentException | file must be provided. | No chat group shared file was provided. | Upload a chat group shared file. |

For other errors, see [Response status codes](error.html) for possible causes.
