# Mute Users by Chat Room Tag

## Feature overview

- Control whether users with a tag can speak in the chat room.
- After this API is called, muted users are added to the chat room mute list.
- You can mute users with a specified tag for a certain period or permanently. A temporary mute is automatically lifted when it expires.
- A user's tags become invalid after the user leaves and then rejoins the chat room.

## Feature activation

EasyIM supports setting tags for users in a chat room and muting users by tag. To use this API, contact the Easemob business team to activate the feature.

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
PUT https://{host}/{org_name}/{app_name}/chatrooms/{chatroom_id}/tag/mute
```

| Parameter           | Type   | Required | Description                                |
| :------------- | :----- | :------- | :---------------------------------- |
| `chatroom_id` | String | Yes       | Chat room ID. |

For details about the parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X PUT 'https://XXXX/XXXX/XXXX/chatrooms/12XXXX11/tag/mute' \
-H 'Content-Type: application/json' \
-H 'Accept: application/json' \
-H 'Authorization: Bearer <YourAppToken>' \
-d '{
    "tag": "t1",
    "mute_duration": 30
}'
```

## Request header fields

For details about the `Content-Type`, `Accept`, and `Authorization` fields, see [Request header fields](overview.html#request-header-fields).

## Request body fields

| Parameter            | Type   | Required | Description                                                         |
| :-------------- | :----- | :------- | :----------------------------------------------------------- |
| `mute_duration` | Long   | Yes       | Mute duration in seconds. For example, if you specify `60`, the mute expires after 60 seconds.<br/>`0` cancels the mute, and `-1` sets a permanent mute. |
| `tag`           | String | Yes       | Tag name. The tag name cannot exceed 32 characters.     |

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The response body contains the following fields:

| Field          | Type | Description                                                    |
| :------------ | :--- | :------------------------------------------------------ |
| `data` | JSON | Actual mute result. |
| - `result` | Bool | Whether the users were successfully muted:<br/> - `true`: Yes.<br/> - `false`: No. |

The other fields in the response body are described below:

| Parameter              | Type   | Description                                                                           |
| :---------------- | :----- | :----------------------------------------------------------------------------- |
| `action`          | String | Request method. |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `uri`             | String | Request URL. |
| `entities`        | JSON Array   | Response entities. |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `properties`      | JSON | Response properties.                                                                     |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `applicationName` | String | App name entered when you created the app in the Easemob Console, identical to the `app_name` request parameter. |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code | Error type           | Error message                       | Possible cause                              | Recommendation     |
| :---------- | :----------------- | :--------- | :------------------------------------ | :----------------------------------- |
| 401         | unauthorized       | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token.                |
| 404         | resource_not_found | grpID XX does not exist!       | The chat room does not exist.                        | Specify a valid chat room ID.                |
| 403         | forbidden_op       | Group tag mute is disabled     | The chat room tag-based mute feature is not activated.          | Contact the Easemob business team to activate the chat room tag-based mute feature. |
| 404         | resource_not_found | group tag not found            | The chat room tag does not exist.                    | Set a chat room tag for the user before performing this operation.   |
| 403 | exceed_limit | tag length exceeds limit! | The tag name exceeds the length limit. | Shorten the tag name. |

For other errors, see [Response status codes](error.html) for possible causes.
