# Retrieve the Chat Room Member List

## Feature overview

Retrieves the chat room member list by page.

Chat room member roles are described below:

| Member role     | Description       | Administrative permissions       |
| :----------- | :----------------------- | :----------------- |
| Regular member     | A chat room member without administrative permissions.                       | Regular members can modify their own chat room information.   |
| Chat room admin | Authorized by the chat room creator to help manage the chat room and has administrative permissions. | Admins can manage regular members in the chat room. You can add up to 99 admins.  |
| Chat room owner | The chat room creator, who has the highest level of permissions in the chat room.               | The chat room owner can designate chat room admins, destroy the chat room, modify chat room information, and manage chat room members.

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
GET https://{host}/{org_name}/{app_name}/chatrooms/{chatroom_id}/users?pagenum={N}&pagesize={N}
```

| Parameter       | Type | Required | Description      |
| :--------- | :--- | :------- | :-------------------- |
| `chatroom_id` | String | Yes       | Chat room ID. |
| `pagenum`  | Int  | No       | Page number to query. The default value is `1`.                                         |
| `pagesize` | Int  | No       | Number of chat room members to display per page. The default value is 1000. The value range is [0,1000]. If the specified value exceeds 1000 then 1000 chat room members are returned. |

For details about other parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X GET https://XXXX/XXXX/XXXX/chatrooms/12XXXX11/users?pagenum=2&pagesize=2     \
-H 'Authorization: Bearer <YourAppToken>'
```

## Request header fields

For a description of the `Authorization` field, see [Request header fields](overview.html#request-header-fields).

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The `data` field in the response body is described below:

| Field                 | Type   | Description   |
| :------------------- | :----- | :------------ |
| `data` | JSON Array | Chat room member information. The server does not sort members, so the returned member list is not guaranteed to be ordered.  |
|  - `owner`  | String | User ID of the chat room owner. Example: {"owner": "user1"}.   |
|  - `member` | String | User ID of a regular chat room member or chat room admin. Example: {"member":"user2"}. |

The other fields in the response body are described below:

| Parameter              | Type   | Description                                                                           |
| :---------------- | :----- | :----------------------------------------------------------------------------- |
| `action`          | String | Request method. |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `params`          | JSON       | Query parameters.                                                   |
| - `pagesize`      | Array      | Expected number of chat room members to display per page.                               |
| - `pagenum`       | Array      | Current page number.                                                   |
| `uri`             | String | Request URL. |
| `entities`        | JSON Array   | Response entities. |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `applicationName` | String | App name entered when you created the app in the EasyIM Console, identical to the `app_name` request parameter. |
| `count` | Number | Actual number of chat room members retrieved in this call. |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |
| 404     | service_resource_not_found | do not find this group:XX | The chat room ID does not exist. | Specify a valid chat room ID. |

For other errors, see [Response status codes](error.html) for possible causes.
