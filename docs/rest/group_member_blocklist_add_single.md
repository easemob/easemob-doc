# Add a User to the Group Blocklist

## Feature overview

- Add a single user to the group blocklist.
- The group owner cannot be added to the group blocklist.
- A user added to the group blocklist is removed from the chat group and can no longer view chat group information or send and receive group chat messages.
- To send and receive messages in the chat group again, the user must first be removed from the blocklist and then rejoin the chat group.
- Adding a user to the blocklist triggers a post-delivery callback. For details, see [Chat Group Member Added to the Group Blocklist](callback_group_room_blocklist.html#add-a-member-to-the-blocklist).

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
POST https://{host}/{org_name}/{app_name}/chatgroups/{group_id}/blocks/users/{username}
```

| Parameter     | Type   | Required | Description                                                        |
| :------- | :----- | :------- | :---------------------------------------------------------- |
| `group_id`  | Int    |  Yes       | Chat group ID. |
| `usernames`  | String    |  Yes       | User ID to be added to the group blocklist. |

For details about other parameters in the request URL, see [Request URL parameters](overview.html#request-url).

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X POST 'https://XXXX/XXXX/XXXX/chatgroups/66XXXX85/blocks/users/user1'   \
-H 'Content-Type: application/json'    \
-H 'Accept: application/json'    \
-H 'Authorization: Bearer <YourAppToken>' 
```

## Request header fields

For details about the `Content-Type`, `Accept`, and `Authorization` fields, see [Request header fields](overview.html#request-header-fields).

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The response body contains the following fields:

| Field           | Type   | Description                                                                          |
| :------------- | :----- | :---------------------------------------------------------------------------- |
| `data` | JSON Array | Response data.|
| - `result`  | Bool   | Whether the user was added successfully: <br/> - `true`: The user was added; <br/> - `false`: The user was not added. |
| - `action`  | String | The operation performed. In this response, the value is `add_blocks`, indicating that the member was added to the group blocklist. |
| - `user`    | String | Added user ID.                                                               |
| - `groupid` | String | Chat group ID.                                                                     |

The other fields are described below:

| Field          | Type | Description                                                                              |
| :------------ | :--- | :-------------------------------------------------------------------------------- |
| `action`          | String | Request method. |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `uri`             | String | Request URL. |
| `entities`        | JSON Array   | Response entities. |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `applicationName` | String | App name entered when you created the app in the EasyIM Console, identical to the `app_name` request parameter. |

If the returned HTTP status code is not `200`, the request fails. See [Error code](#error-code) for possible causes.

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |
| 403     | forbidden_op | users [XX] are not members of this group! | The specified user is not in the chat group. | Specify the user ID of a chat group member. |
| 404     | resource_not_found | grpID XX does not exist! | The chat group does not exist. | Use a valid chat group ID. |
| 403    | forbidden_op   | forbidden operation on group owner!   | The group owner cannot be added to the group blocklist.  |

For other errors, see [Response status codes](error.html) for possible causes.
