# Bulk Remove Chat Group Members

## Feature overview

- Remove multiple chat group members at once. You can remove up to 60 members at a time.
- If none of the specified users are chat group members, the request fails. Removed members are also removed from any message threads they joined in the chat group.
- After removing a chat group member, the server will send a system notification to the chat group members by default. You can set whether to send this notification.
- Removing chat group members triggers a post-delivery callback. For details, see [User Removed from a Chat Group](callback_group_room_leave.html#be-removed).
- Removed chat group members can still retrieve messages that were sent and received in the chat group before their removal.

## Call frequency limit

100 calls/second/App Key

## Request URL

```http
DELETE https://{host}/{org_name}/{app_name}/chatgroups/{group_id}/users/{members}?need_notify=false
```

For details about the parameters in the request URL, see [Request URL parameters](overview.html#request-url).

The query parameters are described below:

| Parameter            | Type   | Required | Description       |
| :-------------- | :----- | :------- | :------------ |
| `group_id`  | Int    |  Yes       | Chat group ID. |
| `members` | String | Yes       | User IDs of the chat group members to remove, separated by commas (","). Specify no more than 60 user IDs at a time, and ensure that the URL does not exceed 4 KB. |
| `need_notify` | Bool   | No       | Whether to send system notifications to chat group members after removing chat group members. <br/> - (Default) `true`: Yes; <br/> - `false`: No.   |

## Request example

```shell
# Replace <YourAppToken> with the App Token generated on your server

curl -X DELETE 'https://XXXX/XXXX/XXXX/chatgroups/66XXXX85/users/ttXXXX81,user2,user3?need_notify=false'  \
-H 'Accept: application/json'  \
-H 'Authorization: Bearer <YourAppToken>' 
```

## Response body fields

If the returned HTTP status code is `200`, the request is successful. The `data` field in the response body is described below:

| Field           | Type   | Description            |
| :------------- | :----- | :------------------- |
| `data` | JSON Array | Response data.|
|  - `result`  | Bool   | Whether the member was removed successfully: <br/> - `true`: The member was removed; <br/> - `false`: The member was not removed. |
|  - `action`  | String | The operation performed. In this response, the value of this field is `remove_member`, indicating removal of chat group members. |
|  - `reason`  | String | The reason why the operation failed.                                                         |
|  - `user`    | String | The user ID of the removed member.                                                    |
|  - `groupid` | String | The chat group ID of the operation.                                                          |

The other fields are described below:

| Field          | Type | Description                                                                              |
| :------------ | :--- | :-------------------------------------------------------------------------------- |
| `action`          | String | Request method. |
| `application`     | String | Unique identifier of the app in the system. It is generated by the system and does not require your attention. |
| `uri`             | String | Request URL. |
| `entities`        | JSON Array   | Response entities. |
| `timestamp`       | Long   | Unix timestamp in milliseconds. |
| `duration`        | Int    | Duration from sending the request to receiving the response, in milliseconds. |
| `organization`    | String | Unique identifier assigned by EasyIM to each company (organization), identical to the `org_name` request parameter. |
| `applicationName` | String | App name entered when you created the app in the EasyIM Console, identical to the `app_name` request parameter. |

## Error code

If the returned HTTP status code is not `200`, the request fails and one of the following error codes may be returned:

| HTTP status code        | Error type | Error message          | Possible cause | Recommendation |
| :----------- | :--- | :------------- | :----------- | :----------- |
| 401     | unauthorized | Unable to authenticate (OAuth) | The token is invalid, expired, or incorrect. | Use a new token. |
| 403     | forbidden_op | users [XX] are not members of this group! | The user is not in the chat group. | Specify the user ID of a chat group member. |
| 403     | forbidden_op | forbidden operation on group owner! | The group owner cannot be removed. | None. |
| 404     | resource_not_found | grpID XX does not exist! | The chat group does not exist. | Use a valid chat group ID. |
| 400     | invalid_parameter | kickMember: kickMembers number more than maxSize : 60 | More than 60 chat group members were specified. | Specify no more than 60 chat group members. |

For other errors, see [Response status codes](error.html) for possible causes.
