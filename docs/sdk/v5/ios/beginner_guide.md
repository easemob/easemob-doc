# Beginner's Guide

EasyIM supports text, image, location, voice, video, and other message types. It also provides one-to-one chat, group chat, chat rooms, offline push, account authentication, user attributes, and user relationships.

## Explore the iOS SDK

The current iOS SDK documentation covers the following core capabilities:

| Feature | Description |
| --- | --- |
| [Message management](message_overview.html) | Send, receive, delete, forward, modify, recall, pin, quote, and extend messages. |
| [Chat group management](group_overview.html) | Manage chat groups, group members, group attributes, and member name cards. |
| [Chat room management](room_overview.html) | Manage chat rooms, members, and chat room attributes. |

For a summary of the currently available features, see [iOS SDK Overview](sdk_overview.html).
