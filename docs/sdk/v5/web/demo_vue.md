# Introduction to the Vue Demo (WebIM)

EasyIM Web provides a sample app for you to try. Follow these steps:

1. Log in to the [Vue 3 Demo](https://webim-vue3.easemob.com/login)

![img](/images/demo/web_vue3_login.png)

2. Enter your mobile phone number, obtain a verification code, and then enter the code.

3. Click **Log In** to log in to the Demo.

## Download the code

- Vue 3: [GitHub](https://github.com/easemob/webim-vue-demo/tree/vue3-miniCore) or [Gitee source code](https://github.com/easemob/webim-vue-demo/tree/vue3-miniCore).

## Run the web-vue3-demo project

Download the project code archive from [GitHub](https://github.com/easemob/webim-vue-demo/tree/vue3-miniCore) or [Gitee](https://github.com/easemob/webim-vue-demo/tree/vue3-miniCore), and then extract it. After extraction, the `webim-vue-demo` folder is the EasyIM Web project directory.
> Make sure the `node` runtime is version 16 or 17.
1. Install the dependencies required by the Demo: Run `npm install` or `yarn` in a terminal.

2. Run the Demo:
   - Run `npm run dev` in a terminal.
   - Visit `http://localhost:9001` in a browser to try `webim-vue3-demo`.

## Main modules

The main modules in the Demo are as follows:

| Module name     | Description                   |
| :----------- | :--------------------- |
| `assets`     | Asset files.             |
| `components` | Components defined in the project.     |
| `views`      | Pages related to login and chat.       |
| `router`     | Routing.                 |
| `store`      | Data managed using Vuex. |
| `utils`      | Utility methods.             |
