title: Web SDK Overview
---

The EasyIM Web SDK provides messaging, conversation, chat group, chat room, user management, presence, and offline push capabilities for web applications and mini programs.

## Features

| Feature category | Description |
| --- | --- |
| [User management](user_relationship.html) | Provides user relationships, user attributes, automatic user information management, and presence subscriptions. |
| [Message management](message_overview.html) | Sends, receives, retrieves, recalls, edits, deletes, forwards, pins, and manages messages. It also supports message reactions, receipts, extensions, quotes, targeted messages, streaming messages, and online-only delivery. |
| [Conversation management](conversation_overview.html) | Retrieves and manages conversation lists, local conversations, unread counts, pinned conversations, conversation tags, and conversation deletion. |
| [Chat group management](group_overview.html) | Creates and manages chat groups, members, group attributes, member attributes, group announcements, group message threads, name cards, and group @ mentions. |
| [Chat room management](room_overview.html) | Manages chat rooms, members, chat room attributes, mute lists, allowlists, blocklists, announcements, and superadmins. |
| [Offline push](push/push_overview.html) | Configures offline push, notification modes, push templates, push extensions, and notification translation. |
