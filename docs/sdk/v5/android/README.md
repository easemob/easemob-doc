title: Android SDK Overview

The EasyIM Android SDK provides messaging, conversation, chat group, chat room, user management, and presence capabilities for Android applications.

## Features

| Feature category | Description |
| --- | --- |
| [User management](user_relationship.html) | Provides user relationships, user attributes, automatic user information management, and presence subscriptions. |
| [Message management](message_overview.html) | Sends, receives, retrieves, searches, recalls, edits, deletes, forwards, pins, and imports messages. It also supports message reactions, receipts, extensions, quotes, targeted messages, stream messages, and online-only delivery. |
| [Conversation management](conversation_overview.html) | Retrieves and manages conversation lists, unread counts, pinned conversations, conversation marks, and conversation deletion. |
| [Chat group management](group_overview.html) | Creates and manages chat groups, members, group attributes, member attributes, group announcements, group message threads, name cards, and group @ mentions. |
| [Chat room management](room_overview.html) | Manages chat rooms, members, chat room attributes, mute lists, allowlists, blocklists, announcements, and superadmins. |
| [Offline push](push/push_overview.html) | Offline push documentation is coming soon. |
