# 如何配置服务器域名

<Toc />

在生产环境中，微信小程序必须配置合法的服务器域名，否则将无法正常访问相关服务。本文介绍如何在微信小程序管理后台中配置服务器域名，具体步骤如下。

## 查看当前应用的服务域名

先从环信控制台 [查看应用服务器域名](/product/console/app_manage.html#查看应用服务器域名)。使用应用专属域名时，添加当前应用的域名；使用集群域名时，添加当前应用对应的集群域名。域名类型不影响小程序后台需要完成的合法域名配置。

SDK 的服务地址配置决定实际连接的目标，小程序后台的合法域名配置决定平台允许访问的目标，两处都需要设置。SDK 参数及示例见 [配置应用专属域名](initialization.html#配置应用专属域名)。

各类连接与后台配置的对应关系如下。

| 连接用途 | 小程序后台配置 | 填写内容 |
| :--- | :--- | :--- |
| REST 请求 | `request` 合法域名。 | 当前应用 REST API 地址对应的 HTTPS 域名。 |
| 消息 WebSocket | `socket` 合法域名。 | 当前应用 WebSocket 地址对应的 WSS 域名；SDK 连接 URL 的路径按初始化说明填写。 |
| 附件上传、下载 | `uploadFile`、`downloadFile` 合法域名。 | 根据实际上传、下载请求目标添加 HTTPS 域名，不能假定两项服务地址覆盖全部附件请求。 |

选择 **创建新的正式版应用** 上线后，应检查正式版域名是否已添加；如果测试环境仍在使用，应保留测试版所需的合法域名。配置完成后，请在开启域名校验的真机环境验证登录、消息及附件。

## 在微信公众平台配置合法域名

1. 打开 [微信公众平台官网](https://mp.weixin.qq.com/)，登录微信小程序账号，进入小程序管理后台首页。
2. 在左侧菜单中找到 **</> 开发** 模块。

![img](/images/applet/config1.png)

3. 进入 **</> 开发** 模块，点击 **开发管理**，然后在 **开发设置** 中找到 **服务器域名** 配置项。

![img](/images/applet/config2.png)

4. 如果是首次配置服务器域名，页面会显示 **开始配置** 按钮。点击该按钮进入配置流程。

![img](/images/applet/config3.png)

5. 在配置服务器信息前，需要先完成身份确认。请由管理员使用微信扫码进行身份认证。

![img](/images/applet/config4.png)

6. 完成管理员身份认证后，进入 **配置服务器信息** 页面，按上表分别填写 **request 合法域名**、**socket 合法域名**，并根据附件功能填写 **uploadFile 合法域名**、**downloadFile 合法域名**。

![img](/images/applet/config5.png)

7. 对照环信控制台 **应用概览 > 开发配置信息 > 域名配置** 中的当前应用地址，确认已添加所需域名。下图为集群域名的历史界面示例，实际地址以当前应用页面为准。

:::tip
抖音小程序、QQ 小程序、百度小程序以及 uni-app 全平台的域名配置规则与微信小程序一致，使用微信小程序栏中的域名即可。
:::

![img](/images/applet/config6.png)

8. 填写域名信息后，点击 **保存并提交** 按钮，完成配置。

![img](/images/applet/config7.png)

9. 配置完成后，如需修改或删除服务器域名，可再次进入 **</> 开发** 模块，打开 **服务器域名** 设置页面进行操作。
