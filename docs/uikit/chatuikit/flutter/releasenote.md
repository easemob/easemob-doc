# Flutter 单群聊 UIKit 更新日志

## 版本 2.3.0-dev.1

#### 新增特性

- 依赖的 `Flutter SDK` 升级至 4.15.2。
- 合并聊天室 UIKit 并完整本地化。

#### 修复

- 修复缩略图显示模糊问题。
- 修复设置空会话没有生效的问题。
- 修复 @ 消息无法正常工作的问题。
- 修复自定义 `MessagesView` 中 `itemBuilder` 为 `null` 时，不会发已读回执的问题。
- 修复弹出键盘后表情面板没有完全遮挡的问题。
- 修复部分插件依赖问题。

## 版本 2.2.0

#### 优化

- 依赖的 `Flutter SDK` 升级至 4.13.0。
- 升级第三方库。
- 修改撤回消息回调。
- 修改群默认头像设置。

#### 修复

- 修复收到会话回执没有标记消息的问题。
- 修复消息列表背景无法点击。

## 版本 2.1.0

#### 新增特性

- 依赖的 `Flutter SDK` 升级至 4.8.2。
- [消息长按菜单样式新增微信风格样式](chatuikit_custom_chat.html#自定义消息长按后显示的操作)；
- [发送附件消息菜单新增微信风格样式](chatuikit_custom_chat.html#自定义消息上下文菜单样式)。

#### 优化

- 修改 `ChatUIKitBottomSheetItem` 为 `ChatUIKitEventAction`。
- 依赖 IM SDK 升级为 `im_flutter_sdk: 4.8.2`。
- 依赖 Flutter 版本升级为 3.19.0。
- 修改主题设置方式。
