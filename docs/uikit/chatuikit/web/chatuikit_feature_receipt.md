# 消息回执

消息回执包括送达回执和已读回执，发送方发送消息后可及时了解接收方是否及时收到并阅读了消息。

## 送达回执	

送达回执用于告知消息发送者，其发送的消息已经成功发送到服务器、接收方以及发送失败。
