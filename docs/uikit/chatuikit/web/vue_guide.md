# 开发文档导航

本文汇总面向 Vue 3 项目的 Vue UIKit 文档。了解产品定位、功能和界面效果，请查看 [产品概述](vue_overview.html) ；具体接入、开发指南、组件和 API 资料已分别整理为下列文档，也可从左侧子菜单进入。

首次使用建议按“开始接入 → 开发指南 → 组件文档 → API 参考”的顺序阅读。使用 AI 编程工具时，可先配置 [AI 辅助开发](vue_development.html#ai-辅助开发) 中的 Skills 或 Vue UIKit 专用 MCP。
