# React Native 单群聊 UIKit 更新日志

## 版本 2.4.8 (2025-07-28)

### 新增特性

- 新增漫游消息拉取特性。

### 修复

- 修复底部弹出菜单组件。
- 修复示例项目中的路由问题。

## 版本 2.4.6 (2025-07-08)

### 优化

- UIKit 不再包含生成的代码。
- 支持开发模式下使用密码登录。
- 支持使用阿里云验证码工具。
- 升级 react-native 至 0.76.9。

- 修复输入组件的问题。
- 修复自定义消息样式问题。
