# React Native 单群聊 UIKit 更新日志

## 版本 2.5.0

- 修复登录页面状态显示异常的问题。
- 优化欢迎页面切换时加载动画不关闭的问题。
- 优化 UIKit：改善简单图标动画组件性能，显著降低 CPU 使用率。
- 新增自定义数据层支持，允许灵活的业务处理。例如：应用的手机号好友搜索功能使用此接口。
- 优化应用中图片消息预览：新增自定义图片预览组件支持。
- 优化应用中视频消息预览：新增自定义视频预览组件支持。
- 优化动画：新增语音图片动画组件。
