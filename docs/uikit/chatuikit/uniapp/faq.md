## Vue3 项目在 H5 平台发布的注意事项

Vue3 项目在 H5 平台发布时，会默认启用 Tree Shaking（摇树优化）机制，仅打包明确引用的 API 和组件，以减小最终构建包的体积。该优化会自动移除未明确引用的模块，进而引发线上环境出现登录失败、页面白屏等问题，而在本地开发环境中这些问题通常无法复现。

为确保发布版本包含完整的依赖模块，需在 `manifest.json` 中关闭 `Tree Shaking` 配置，打包 Vue3 项目后部署至 H5 平台。
