## 小程序域名如何配置？

小程序在使用环信即时通讯服务时，需要在微信公众平台配置服务器域名。详情请参考[小程序域名配置文档](https://doc.easemob.com/document/applet/wechat.html#配置服务器域名)。

## Vue3 项目在 H5 平台发布时出现登录失败、页面白屏等问题

**问题描述：**

Vue3 在 H5 平台发行时，为了优化包体积大小，会默认启动 Tree Shaking（摇树优化），仅打包明确引用的 API 和组件。

该机制可能导致部分未明确引用的模块被排除，从而引发线上运行时出现登录失败、页面白屏等问题，而本地开发环境通常不会暴露此类问题。

**解决方案：**

为确保正确打包所有依赖模块，需在 `manifest.json` 中关闭 `Tree Shaking`，然后打包 Vue3 项目，部署至 H5 平台。
